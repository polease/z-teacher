# 五年级 · 英语语言艺术 / Grade 5 · English Language Arts

> 对齐标准：Common Core State Standards for English Language Arts, Grade 5 (CCSS-ELA G5)。五年级强调引用文本佐证、概括主旨与主题、跨文本整合，并写出结构清晰的多段落作文。

## 本年级总目标 / Year Goals
学生能准确引用文本细节支撑推断与分析，从文学与信息文本中概括主题与主旨。能撰写观点、说明与记叙三类连贯作文，使用证据并完成研究项目。能在讨论与汇报中清晰表达，并正确运用完成时态、关联连词与逗号规则。
Students cite textual evidence to support inferences and analysis, and summarize themes and main ideas from literary and informational texts. They write coherent opinion, informative, and narrative pieces using evidence and complete research projects. They speak and present clearly and correctly use perfect verb tenses, correlative conjunctions, and comma rules.

## 1. 基础阅读技能 / Foundational Skills

### 1.1 多音节词与词素分析 / Multisyllabic Words & Morphology
- **学什么 / What**：综合运用语音、音节模式与词素（roots, prefixes, suffixes）解码不熟悉的多音节词。
- **掌握标准 / Mastery**：能独立准确读出生僻多音节词。
- **例子 / Example**：拆解 "transportation" 为 trans-port-ation 来读音解义。

### 1.2 流利阅读 / Reading Fluency
- **学什么 / What**：以恰当速度、准确度与表达力（accuracy, rate, expression）朗读并理解。
- **掌握标准 / Mastery**：朗读时停顿、语气符合标点与含义，理解到位。
- **例子 / Example**：有感情地朗读对话并体现人物情绪。

## 2. 文学类阅读 / Reading Literature

### 2.1 准确引用文本 / Quoting Accurately
- **学什么 / What**：准确引用文本（quote accurately）以解释明示内容并作推断（inference）。
- **掌握标准 / Mastery**：能用引号标注原文支撑回答。
- **例子 / Example**：引用「他攥紧拳头」推断人物愤怒。

### 2.2 提炼主题并概括 / Determining Theme & Summarizing
- **学什么 / What**：从角色反应、挑战或叙述者反思中提炼主题（theme），并概括文本（summarize）。
- **掌握标准 / Mastery**：能用一句话表达主题并不夹带个人观点地概括。
- **例子 / Example**：从角色克服恐惧得出「勇气源于坚持」的主题。

### 2.3 用细节比较人物/场景/事件 / Comparing Characters, Settings, Events
- **学什么 / What**：用具体细节比较两个人物、场景或事件（compare with details）。
- **掌握标准 / Mastery**：能指出异同并引用细节。
- **例子 / Example**：比较故事开头与结尾主角态度的变化。

### 2.4 理解修辞语言 / Figurative Language
- **学什么 / What**：理解词句含义，含比喻语言（figurative language）如明喻、暗喻。
- **掌握标准 / Mastery**：能解释修辞表达的实际含义。
- **例子 / Example**："时间是小偷" 暗喻时间悄悄流逝。

### 2.5 文本结构分析 / Structure of Stanzas, Scenes, Chapters
- **学什么 / What**：分析诗节、场景或章节（stanzas, scenes, chapters）如何衔接构成整体。
- **掌握标准 / Mastery**：能说明某章节对全篇的作用。
- **例子 / Example**：解释戏剧第二幕如何推进冲突。

### 2.6 叙述者/说话者视角 / Narrator & Speaker's Point of View
- **学什么 / What**：分析叙述者或说话者视角（point of view）如何影响事件描写。
- **掌握标准 / Mastery**：能判断第一/第三人称及其影响。
- **例子 / Example**：第一人称使读者只知主角所见所想。

### 2.7 视觉与多媒体要素 / Visual & Multimedia Elements
- **学什么 / What**：分析插图、图像等多媒体要素如何增强文本含义、语气或美感（multimedia elements）。
- **掌握标准 / Mastery**：能说明插画对故事氛围的作用。
- **例子 / Example**：阴暗插图烘托惊悚情节。

### 2.8 比较同体裁故事主题 / Comparing Themes Across Same Genre
- **学什么 / What**：比较同体裁（如冒险、神话）故事处理相似主题的方式（compare approaches to themes）。
- **掌握标准 / Mastery**：能对两则故事的主题处理作对比。
- **例子 / Example**：比较两个神话对「贪婪」的不同结局。

## 3. 信息类阅读 / Reading Informational

### 3.1 引用并推断 / Quoting & Inferring
- **学什么 / What**：准确引用信息文本支撑明示内容与推断。
- **掌握标准 / Mastery**：能用原文证据回答推断性问题。
- **例子 / Example**：引用数据推断某趋势的原因。

### 3.2 两个及以上主旨与概括 / Two or More Main Ideas & Summary
- **学什么 / What**：找出两个或更多主旨（main ideas），用关键细节支撑并概括。
- **掌握标准 / Mastery**：能列出多个主旨并客观概括全文。
- **例子 / Example**：一篇文章同时讲「污染成因」与「治理方法」两个主旨。

### 3.3 概念/人物/事件的关系 / Relationships & Interactions
- **学什么 / What**：依据文本说明两个及以上个体、事件、概念间的关系或互动（relationships/interactions）。
- **掌握标准 / Mastery**：能描述因果或先后关系。
- **例子 / Example**：解释发明如何引发社会变化。

### 3.4 学术与专业词汇 / Academic & Domain-specific Vocabulary
- **学什么 / What**：判定学术性与专业领域词汇（domain-specific words）含义。
- **掌握标准 / Mastery**：能用上下文与词素推断专业词义。
- **例子 / Example**：在科学文中理解 "evaporation"。

### 3.5 比较多篇文本结构 / Comparing Text Structures
- **学什么 / What**：比较两篇及以上文本的整体结构（structure: chronology, comparison, cause/effect, problem/solution）。
- **掌握标准 / Mastery**：能识别并对比文本组织方式。
- **例子 / Example**：一篇按时间顺序、一篇按因果叙述同一事件。

### 3.6 多重记述与视角 / Multiple Accounts & Point of View
- **学什么 / What**：分析对同一事件的多种记述（multiple accounts），辨别视角异同。
- **掌握标准 / Mastery**：能比较两篇报道的侧重与立场。
- **例子 / Example**：两位目击者对同一场比赛的不同描述。

### 3.7 高效查找答案 / Locating Answers Efficiently
- **学什么 / What**：从多种印刷与数字资源（print & digital sources）高效查找问题答案或解决问题。
- **掌握标准 / Mastery**：能快速定位信息所在段落或资源。
- **例子 / Example**：用目录、索引、搜索关键词找资料。

### 3.8 分析理由与证据 / Analyzing Reasons & Evidence
- **学什么 / What**：解释作者用哪些理由与证据（reasons & evidence）支持哪些观点。
- **掌握标准 / Mastery**：能把具体证据与对应论点配对。
- **例子 / Example**：指出作者用统计数据支持「应多运动」。

### 3.9 整合多文本信息 / Integrating Information
- **学什么 / What**：整合多篇同主题文本的信息（integrate information）以便写作或发言。
- **掌握标准 / Mastery**：能综合两篇以上资料形成知识性表达。
- **例子 / Example**：综合三篇文章写一段关于火山的介绍。

## 4. 写作 / Writing

### 4.1 观点类写作 / Opinion Writing
- **学什么 / What**：写观点文，逻辑排序理由（logically ordered reasons），用事实与细节支撑，使用连接词，结尾正式。
- **掌握标准 / Mastery**：观点明确、理由有序、有事实支撑、有结论段。
- **例子 / Example**：「学校应延长课间」并给三条有序理由。

### 4.2 说明类写作 / Informative/Explanatory Writing
- **学什么 / What**：清楚说明主题，分组信息，使用排版、插图、多媒体，精确用词与专业词汇。
- **掌握标准 / Mastery**：信息分组合理、用词准确、有引导与总结。
- **例子 / Example**：写「水循环」并配图表说明各阶段。

### 4.3 记叙类写作 / Narrative Writing
- **学什么 / What**：运用叙事技巧、节奏、对话、描写、过渡、五感细节（sensory details）与有力结尾。
- **掌握标准 / Mastery**：情节连贯、人物鲜活、有铺垫与收束。
- **例子 / Example**：写一次露营经历，用对话与感官描写营造氛围。

### 4.4 连贯写作 / Coherent Writing
- **学什么 / What**：使行文发展与组织契合任务、目的与读者（task, purpose, audience）。
- **掌握标准 / Mastery**：段落衔接自然、结构清晰。
- **例子 / Example**：用过渡句连接段落使逻辑顺畅。

### 4.5 计划/修改/编辑/重写 / Planning, Revising, Editing
- **学什么 / What**：在他人指导下规划、修改、编辑、重写（plan, revise, edit, rewrite）以提升作品。
- **掌握标准 / Mastery**：能根据反馈改进结构与用词。
- **例子 / Example**：根据同伴建议补充细节、改正语法。

### 4.6 用技术写作与键盘打字 / Using Technology & Keyboarding
- **学什么 / What**：用数字工具写作与发表，一次能键入至少两页（keyboarding two pages）。
- **掌握标准 / Mastery**：能熟练打字并使用文档工具协作。
- **例子 / Example**：在文档中合作完成并发布一篇短文。

### 4.7 研究项目 / Research Projects
- **学什么 / What**：开展简短研究项目，运用多种来源（multiple sources）调查问题。
- **掌握标准 / Mastery**：能围绕问题查阅并整合多来源资料。
- **例子 / Example**：研究「再生能源」并用三种来源。

### 4.8 概括转述与列参考 / Summarizing, Paraphrasing & Citing
- **学什么 / What**：概括或转述信息，注明来源（sources）并列基础参考书目（basic bibliography）。
- **掌握标准 / Mastery**：能用自己的话转述并标注出处。
- **例子 / Example**：在文末列出三条来源清单。

### 4.9 引用证据支持分析 / Drawing Evidence to Support Analysis
- **学什么 / What**：从文学或信息文本引证（draw evidence）以支持分析、反思与研究。
- **掌握标准 / Mastery**：能在写作中嵌入并解释文本证据。
- **例子 / Example**：写读后感时引用关键句论证主题。

## 5. 口语与倾听 / Speaking & Listening

### 5.1 有效讨论 / Engaging in Discussions
- **学什么 / What**：参与有准备的合作讨论，承担角色（roles），提问回应、得出结论（draw conclusions）。
- **掌握标准 / Mastery**：能轮流发言、扣住话题、推进结论。
- **例子 / Example**：小组讨论书中角色动机并形成共识。

### 5.2 概括多形式文本/媒体 / Summarizing Texts & Media
- **学什么 / What**：概括以多种媒介、形式呈现的文本或信息（diverse media & formats）。
- **掌握标准 / Mastery**：能口头概括视频、图表、口述内容要点。
- **例子 / Example**：看完短片后口头总结主旨。

### 5.3 概括说话者的观点与证据 / Summarizing a Speaker's Points
- **学什么 / What**：概括说话者的观点（points），并指出其支持理由与证据。
- **掌握标准 / Mastery**：能复述观点并辨别支撑证据。
- **例子 / Example**：总结同学演讲的主张及其例证。

### 5.4 汇报与展示 / Reporting & Presenting
- **学什么 / What**：按逻辑顺序汇报主题，用事实细节，配音频/视觉（audio/visual）增强。
- **掌握标准 / Mastery**：表达清晰、有条理、配辅助资料。
- **例子 / Example**：用幻灯片展示研究成果。

### 5.5 调整正式/非正式语域 / Adapting Formality
- **学什么 / What**：按场合调整正式或非正式英语（formal/informal English）。
- **掌握标准 / Mastery**：能区分课堂汇报与日常交流的用语。
- **例子 / Example**：演讲用正式语，小组闲聊用口语。

## 6. 语言规范 / Language

### 6.1 连词/介词/感叹词 / Conjunctions, Prepositions, Interjections
- **学什么 / What**：解释连词、介词、感叹词（conjunctions, prepositions, interjections）的功能。
- **掌握标准 / Mastery**：能识别并正确使用三类词。
- **例子 / Example**：在句中找出 "and"（连词）、"under"（介词）、"Wow!"（感叹词）。

### 6.2 动词完成时态 / Perfect Verb Tenses
- **学什么 / What**：使用完成时态（had walked, has walked, will have walked）。
- **掌握标准 / Mastery**：能在合适语境用过去、现在、将来完成时。
- **例子 / Example**：「By noon, she will have finished.」

### 6.3 纠正时态不当转换 / Correcting Tense Shifts
- **学什么 / What**：识别并纠正动词时态的不当转换（inappropriate shifts in tense）。
- **掌握标准 / Mastery**：能保持句子或段落时态一致。
- **例子 / Example**：把 "He runs and then jumped" 改为时态一致。

### 6.4 关联连词 / Correlative Conjunctions
- **学什么 / What**：使用成对的关联连词（either/or, neither/nor, both/and）。
- **掌握标准 / Mastery**：能成对正确搭配。
- **例子 / Example**：「Either you stay or you go.」

### 6.5 逗号用法 / Comma Usage
- **学什么 / What**：在引导成分、并列、反意疑问、直接称呼（introductory elements, series, tag questions, direct address）中用逗号。
- **掌握标准 / Mastery**：能正确放置各类逗号。
- **例子 / Example**：「Yes, Tom, you are right, aren't you?」

### 6.6 标题标点 / Punctuating Titles
- **学什么 / What**：用下划线、引号或斜体标示作品标题（titles of works）。
- **掌握标准 / Mastery**：能区分书名与文章标题的标注方式。
- **例子 / Example**：书名用斜体，短文标题用引号。

### 6.7 拼写 / Spelling
- **学什么 / What**：拼写常用词，必要时查阅参考资料。
- **掌握标准 / Mastery**：能正确拼写并自查纠错。
- **例子 / Example**：核对 "necessary" 的拼写。

### 6.8 扩展/合并/缩减句子 / Expanding, Combining, Reducing Sentences
- **学什么 / What**：为表达意义、读者兴趣与风格而扩展、合并、缩减句子（sentence combining）。
- **掌握标准 / Mastery**：能把短句合并为信息更密的句子。
- **例子 / Example**：把两短句合成一句复合句。

### 6.9 英语变体比较 / Varieties of English
- **学什么 / What**：比较故事、戏剧、诗歌中英语的不同变体（dialects, registers）。
- **掌握标准 / Mastery**：能识别方言或正式/非正式语域差异。
- **例子 / Example**：比较人物对话中的方言与旁白的标准语。

### 6.10 修辞语言（明喻/暗喻/习语）/ Figurative Language & Idioms
- **学什么 / What**：解释明喻、暗喻、习语、谚语、格言（similes, metaphors, idioms, adages, proverbs）。
- **掌握标准 / Mastery**：能说明其比喻含义。
- **例子 / Example**："break a leg" 意为「祝好运」。

### 6.11 词义关系 / Word Relationships
- **学什么 / What**：理解同义、反义、近义词（synonyms, antonyms, homographs）的关系以辨义。
- **掌握标准 / Mastery**：能用词义关系帮助理解词汇。
- **例子 / Example**：辨析 "happy" 与 "joyful" 的细微差别。

### 6.12 学术与专业词汇运用 / Using Academic & Domain Vocabulary
- **学什么 / What**：习得并准确使用年级水平的学术与专业词汇（general academic & domain-specific words）。
- **掌握标准 / Mastery**：能在写作与口语中恰当使用新词。
- **例子 / Example**：写说明文时用 "for example, in contrast" 等学术连接词。

## 游戏化玩法建议 / Gamification Hooks
- **文学类阅读 / RL**：「证据侦探」——读完段落后在文中高亮正确引文锁定推断，错误引文扣分。
- **信息类阅读 / RI**：「主旨拼图」——把分散的关键细节拖到对应的多个主旨框中，集齐解锁概括关卡。
- **写作 / W**：「作文工坊」——分步骤完成计划、起草、修改三个房间，每步获得徽章，最终发布作品。
- **口语与倾听 / SL**：「圆桌挑战」——AI 扮演讨论同伴，玩家需提问、回应并总结观点以推进对话评分。
- **语言规范 / L**：「逗号迷宫」与「时态时光机」——在句子中放置逗号或切换完成时态过关，连续正确点亮路径。
