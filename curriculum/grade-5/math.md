# 五年级 · 数学 / Grade 5 · Mathematics

> 对齐标准：Common Core State Standards for Mathematics, Grade 5 (CCSS-M G5)。本年级聚焦小数与分数运算的熟练度、体积概念以及坐标平面入门。 / Aligned to CCSS-M Grade 5, focusing on fluency with decimals and fractions, the concept of volume, and an introduction to the coordinate plane.

## 本年级总目标 / Year Goals
五年级学生要把多位数乘除法做到熟练，并把小数运算扩展到百分位、分数运算扩展到异分母。 / Grade 5 students become fluent with multi-digit multiplication and division, extend decimal operations to hundredths, and master operations with unlike-denominator fractions.
他们还要建立体积这一全新几何量的概念，并学会在坐标平面第一象限描点解决实际问题。 / They also build the new geometric measure of volume and learn to graph points in the first quadrant of the coordinate plane to solve real-world problems.

## 1. 运算与代数思维 / Operations & Algebraic Thinking
### 1.1 写并解读含括号的表达式 / Write & Interpret Expressions with Grouping Symbols
- **学什么 / What**：用括号、方括号、花括号写数值表达式，并按运算顺序求值（grouping symbols, order of operations）。
- **掌握标准 / Mastery**：能正确处理嵌套括号并先算括号内的部分。
- **例子 / Example**：`2 × (8 + 7) = 30`，而 `2 × 8 + 7 = 23`。

### 1.2 用语言描述表达式 / Translate Words to Expressions
- **学什么 / What**：把文字描述写成表达式，且不必实际计算结果（writing expressions, interpreting）。
- **掌握标准 / Mastery**：能识别「再翻一倍」「比……多 3」对应的运算结构。
- **例子 / Example**：「把 18 与 6 之和加倍」写作 `2 × (18 + 6)`。

### 1.3 生成与分析数列规律 / Generate & Analyze Patterns
- **学什么 / What**：依据两条不同规则各生成一组数列，并比较对应项之间的关系（patterns, relationships）。
- **掌握标准 / Mastery**：能说出两数列对应项的倍数或差值关系。
- **例子 / Example**：规则「加 3」得 0,3,6,9；规则「加 6」得 0,6,12,18；发现第二组始终是第一组的 2 倍。

### 1.4 组成有序对并作图 / Form Ordered Pairs & Graph
- **学什么 / What**：把两组数列对应项组成有序对，并描在坐标平面上（ordered pairs, graphing）。
- **掌握标准 / Mastery**：能从图形上读出两数列的关系。
- **例子 / Example**：把上例组成 (0,0),(3,6),(6,12)，连线为一条直线。

## 2. 十进制数与运算 / Number & Operations in Base Ten
### 2.1 位值与 10 倍/十分之一关系 / Place Value & ×10 / ÷10
- **学什么 / What**：某一位上的数字是其右边一位的 10 倍、是其左边一位的十分之一（place value）。
- **掌握标准 / Mastery**：能解释 700 中的 7 是 70 中 7 的 10 倍。
- **例子 / Example**：`0.7` 是 `7` 的十分之一。

### 2.2 10 的幂与指数 / Powers of 10 & Exponents
- **学什么 / What**：用整数指数表示 10 的幂，理解乘除以 10 的幂时小数点的移动规律（exponents, powers of 10）。
- **掌握标准 / Mastery**：能用指数解释乘除 10 的幂为何移动小数点位数与零的个数。
- **例子 / Example**：`10² = 100`；`3.6 × 10³ = 3600`。

### 2.3 读写比较千分位小数 / Read, Write & Compare Decimals to Thousandths
- **学什么 / What**：用基数形式、数字形式、展开形式读写到千分位的小数，并用 >、=、< 比较（decimals to thousandths）。
- **掌握标准 / Mastery**：能用展开式写出小数并逐位比较大小。
- **例子 / Example**：`347.392 = 300 + 40 + 7 + 0.3 + 0.09 + 0.002`。

### 2.4 小数四舍五入 / Round Decimals
- **学什么 / What**：把小数四舍五入到任意指定位（rounding decimals）。
- **掌握标准 / Mastery**：能根据下一位判断进位与舍去。
- **例子 / Example**：`2.748` 四舍五入到百分位为 `2.75`。

### 2.5 多位数乘法（标准算法）/ Multi-Digit Multiplication
- **学什么 / What**：用标准算法熟练计算多位整数乘法（standard algorithm）。
- **掌握标准 / Mastery**：能准确计算三位数乘两位数及以上。
- **例子 / Example**：`436 × 27 = 11772`。

### 2.6 多位数除法 / Multi-Digit Division
- **学什么 / What**：四位数被除数除以两位数除数，求商与余数（division）。
- **掌握标准 / Mastery**：能用矩形阵列、面积模型或长除法并解释步骤。
- **例子 / Example**：`5184 ÷ 24 = 216`。

### 2.7 小数加减乘除到百分位 / Decimal Operations to Hundredths
- **学什么 / What**：用具体模型、画图与位值策略对到百分位的小数做加减乘除（decimal operations）。
- **掌握标准 / Mastery**：能对齐小数点并解释运算过程。
- **例子 / Example**：`3.45 + 2.6 = 6.05`；`1.2 × 0.5 = 0.6`。

## 3. 分数 / Number & Operations—Fractions
### 3.1 异分母分数加减 / Add & Subtract Unlike Fractions
- **学什么 / What**：通过通分把异分母分数（含带分数）相加减（unlike denominators, common denominator）。
- **掌握标准 / Mastery**：能找出公分母并约分结果。
- **例子 / Example**：`2/3 + 5/4 = 8/12 + 15/12 = 23/12`。

### 3.2 分数应用题与估算 / Fraction Word Problems & Estimation
- **学什么 / What**：解决加减分数的实际问题，并用基准分数判断答案是否合理（benchmark fractions）。
- **掌握标准 / Mastery**：能判断 `2/5 + 1/2` 大约接近 1 而不是 2。
- **例子 / Example**：估算 `3/7 + 1/2` 约为 1。

### 3.3 把分数理解为除法 / Fractions as Division
- **学什么 / What**：理解分数 a/b 就是 a÷b，并解决整数平均分的应用题（fraction as division）。
- **掌握标准 / Mastery**：能把「3 个披萨分给 4 人」写成 `3/4`。
- **例子 / Example**：`3 ÷ 4 = 3/4`。

### 3.4 分数乘分数与乘整数 / Multiply Fractions
- **学什么 / What**：用面积模型理解分数乘分数、分数乘整数（area model, multiplication）。
- **掌握标准 / Mastery**：能用长方形面积说明 `(a/b)×(c/d)=ac/bd`。
- **例子 / Example**：`2/3 × 4/5 = 8/15`。

### 3.5 把乘法视为缩放 / Multiplication as Scaling
- **学什么 / What**：不必计算就能判断乘以大于、等于或小于 1 的数会放大、不变还是缩小（scaling, resizing）。
- **掌握标准 / Mastery**：能解释乘以 `3/4` 为何使结果变小。
- **例子 / Example**：`6 × 1/2 = 3`（变小）；`6 × 2 = 12`（变大）。

### 3.6 单位分数与整数互除 / Divide with Unit Fractions
- **学什么 / What**：单位分数除以非零整数、整数除以单位分数（unit fraction division）。
- **掌握标准 / Mastery**：能画图说明 `1/3 ÷ 2` 与 `4 ÷ 1/5`。
- **例子 / Example**：`1/3 ÷ 2 = 1/6`；`4 ÷ 1/5 = 20`。

## 4. 测量与数据 / Measurement & Data
### 4.1 同制度内单位换算 / Convert Units within a System
- **学什么 / What**：在同一度量制内换算单位并解决多步应用题（unit conversion）。
- **掌握标准 / Mastery**：能完成厘米↔米、克↔千克等多步换算。
- **例子 / Example**：`2.5 km = 2500 m`。

### 4.2 含分数的折线图 / Line Plots with Fractions
- **学什么 / What**：用 1/2、1/4、1/8 单位作折线图并对数据做运算（line plot, fractions）。
- **掌握标准 / Mastery**：能从折线图读出数据并求重新平均分配的结果。
- **例子 / Example**：把各杯液体平均分配，求每杯应有的量。

### 4.3 体积概念与单位立方体 / Volume Concept & Unit Cubes
- **学什么 / What**：体积是占据空间的量，用单位立方体度量（volume, unit cube）。
- **掌握标准 / Mastery**：能用 1 立方单位无缝填满并计数。
- **例子 / Example**：用 24 个单位立方体填满一个盒子，体积为 24 立方单位。

### 4.4 体积公式 / Volume Formulas
- **学什么 / What**：用 `V = 长×宽×高 = 底面积×高` 求长方体体积（volume formula）。
- **掌握标准 / Mastery**：能在两种公式之间灵活转换。
- **例子 / Example**：`V = 4 × 3 × 2 = 24` 立方单位。

### 4.5 复合图形体积可加性 / Additive Volume
- **学什么 / What**：把不规则立体拆成两个长方体，体积相加（additive volume）。
- **掌握标准 / Mastery**：能分解 L 形立体并求总体积。
- **例子 / Example**：`V = (4×2×3) + (2×2×3) = 24 + 12 = 36`。

## 5. 几何 / Geometry
### 5.1 坐标平面第一象限 / First-Quadrant Coordinate Plane
- **学什么 / What**：认识 x 轴、y 轴、原点，用有序对描点（coordinate plane, ordered pairs）。
- **掌握标准 / Mastery**：能正确解释 (x,y) 中两数的含义。
- **例子 / Example**：点 (3,5) 表示向右 3、向上 5。

### 5.2 用坐标解决实际问题 / Real-World Coordinate Problems
- **学什么 / What**：用坐标平面表示并解决数学与实际问题（graphing real-world problems）。
- **掌握标准 / Mastery**：能把情境数据描点并解读趋势。
- **例子 / Example**：把每天存款记录描点，看储蓄增长。

### 5.3 二维图形分类层级 / Hierarchy of 2-D Shapes
- **学什么 / What**：依据属性把二维图形分类，理解子类继承父类的所有属性（hierarchy, attributes）。
- **掌握标准 / Mastery**：能解释「所有正方形都是矩形，但矩形不都是正方形」。
- **例子 / Example**：正方形 ⊂ 矩形 ⊂ 平行四边形 ⊂ 四边形。

## 游戏化玩法建议 / Gamification Hooks
- **运算与代数思维 / OA**：「括号炸弹拆除」——玩家移动括号位置改变表达式的值，命中目标数即拆弹成功。
- **十进制数与运算 / NBT**：「小数点滑梯」——乘除 10 的幂时拖动小数点到正确位置，过关。
- **分数 / Fractions**：「披萨工坊」——用面积模型切割并拼合披萨完成分数乘除订单。
- **测量与数据 / MD**：「方块建造师」——用单位立方体在 3D 网格中堆出指定体积，复合关卡需拆分加和。
- **几何 / Geometry**：「坐标寻宝」——按有序对线索在第一象限地图描点找到宝藏，并按形状属性把宝石归类入袋。
