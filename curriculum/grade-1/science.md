# 一年级 · 科学 / Grade 1 · Science

> 对齐标准：美国新一代科学标准（Next Generation Science Standards, Grade 1）。本年级通过光与声、动植物结构、亲代与子代、太空规律四大主题，培养观察、提问与设计解决方案的能力。

## 本年级总目标 / Year Goals
一年级学生通过观察与动手探究，理解声音由振动产生、光让物体可见，并发现可观察的自然规律。
First graders use observation and hands-on inquiry to understand that sound comes from vibration and light makes objects visible, and to discover observable patterns in nature.
他们认识动植物的器官如何帮助生存、子代如何像亲代，并观察日月星辰的规律，进而尝试设计简单的解决方案。
They learn how plant and animal parts help survival, how offspring resemble parents, and observe patterns of the sun, moon, and stars, then design simple solutions.

## 1. 波：光与声 / Waves: Light & Sound（1-PS4）

### 1.1 振动产生声音 / Vibrating Materials Make Sound
- **学什么 / What**：通过实验提供证据，说明振动的物体能发出声音（vibrating materials make sound）。
- **掌握标准 / Mastery**：能展示让物体振动就有声音、停止振动声音就消失。
- **例子 / Example**：拨动橡皮筋或敲鼓面，看到/感到振动并听到声音。

### 1.2 声音使物体振动 / Sound Makes Materials Vibrate
- **学什么 / What**：说明声音也能让物体振动（sound can make materials vibrate）。
- **掌握标准 / Mastery**：能举出声音引起物体抖动的例子。
- **例子 / Example**：大声说话时纸杯上的米粒会跳动。

### 1.3 物体被照亮才能看见 / Objects Are Seen Only When Illuminated
- **学什么 / What**：理解物体只有被照亮或反射光进入眼睛时才看得见（objects can be seen only when illuminated）。
- **掌握标准 / Mastery**：知道在全黑环境里看不见东西，有光才看得见。
- **例子 / Example**：关灯后看不见玩具，打开手电就看见了。

### 1.4 不同材料对光路的影响 / How Materials Affect the Path of Light
- **学什么 / What**：观察光遇到透明、半透明、不透明材料的不同结果，认识影子与镜面反射（transparent, translucent, opaque; shadows; mirror reflection）。
- **掌握标准 / Mastery**：能区分光能否穿过材料，知道不透明物挡光成影、镜子能反射光。
- **例子 / Example**：光穿过玻璃（透明）、被纸挡住成影（不透明）、被镜子反射改变方向。

### 1.5 用光或声设计远距离通信装置 / Design a Device to Communicate at a Distance
- **学什么 / What**：用光或声音设计并制作一个能远距离传递信息的装置（design a device using light or sound to communicate）。
- **掌握标准 / Mastery**：能做出并解释一个用闪光或声响发送约定信号的装置。
- **例子 / Example**：用手电筒「长闪一短闪」表示「你好」，或用罐子电话传话。

## 2. 结构与功能 / Structure & Function（1-LS1）

### 2.1 植物的外部器官帮助生存 / Plant Parts Help Survival
- **学什么 / What**：说明植物的根、茎、叶、花等外部器官如何帮助它生存、生长、满足需要（external plant parts）。
- **掌握标准 / Mastery**：能说出根吸水、叶接受阳光、花引来传粉者。
- **例子 / Example**：根把水送上去，叶子晒太阳制造养分。

### 2.2 动物的外部器官帮助生存 / Animal Parts Help Survival
- **学什么 / What**：说明动物的眼、耳、腿、爪、嘴、翅等器官如何帮助它生存（external animal parts）。
- **掌握标准 / Mastery**：能把器官与功能配对，如「翅膀—飞行」「爪子—抓握」。
- **例子 / Example**：兔子的长耳朵帮它听清危险声音。

### 2.3 仿生设计 / Biomimicry
- **学什么 / What**：模仿动植物用器官解决问题的方式，设计解决人类问题的方法（mimic plants/animals to solve human problems）。
- **掌握标准 / Mastery**：能说出一个受动植物启发的设计点子。
- **例子 / Example**：模仿带钩的苍耳种子发明了魔术贴；模仿鸭蹼做出脚蹼。

## 3. 遗传与亲代行为 / Heredity & Parent Behavior（1-LS3, 1-LS1）

### 3.1 子代像但不完全等同于亲代 / Offspring Resemble but Differ from Parents
- **学什么 / What**：通过观察发现幼体长得像父母，但不完全一样（young are like, not identical to, parents）。
- **掌握标准 / Mastery**：能指出小狗和狗妈妈的相似处与不同处。
- **例子 / Example**：小猫像猫妈妈有胡须和尾巴，但花色可能不同。

### 3.2 亲代帮助子代生存的行为 / Parent Behaviors That Help Offspring Survive
- **学什么 / What**：认识亲代与子代之间帮助子代生存的行为，包括信号与照料（signals, care behaviors）。
- **掌握标准 / Mastery**：能举出父母喂食、保护、教导，子代发出叫声求助等例子。
- **例子 / Example**：小鸟张嘴鸣叫，鸟妈妈就来喂虫子。

## 4. 太空系统 / Space Systems（1-ESS1）

### 4.1 日月星辰的可观察规律 / Observable Patterns of Sun, Moon & Stars
- **学什么 / What**：观察并描述太阳、月亮、星星可预测的规律，如昼夜交替、太阳东升西落（observable, predictable patterns）。
- **掌握标准 / Mastery**：能说出白天有太阳、晚上看见月亮星星，太阳从东边升起、西边落下。
- **例子 / Example**：早上太阳在东边，傍晚落在西边。

### 4.2 季节白昼长短的变化 / Seasonal Changes in Daylight
- **学什么 / What**：相对比较不同季节白昼长短的变化（amount of daylight changes with seasons）。
- **掌握标准 / Mastery**：知道夏天白天更长、冬天白天更短（作相对比较，不要求时长数据）。
- **例子 / Example**：夏天傍晚天还亮着可以玩，冬天很早就天黑了。

## 游戏化玩法建议 / Gamification Hooks
- **波：声音 / Sound**：「振动音乐家」——点拨虚拟橡皮筋/鼓面，振动越大音量越大，停止触碰声音消失。Pluck virtual rubber bands and drums; bigger vibration means louder sound, stopping it goes silent.
- **波：光 / Light**：「黑屋探照灯」——黑屏中拖动手电照亮物体才能找到隐藏星星过关。Drag a flashlight in a dark room to illuminate and find hidden stars.
- **光的材料 / Light & Materials**：「光线闯关」——把透明/不透明/镜子方块摆放成让光束到达目标的路径。Place transparent, opaque, and mirror blocks to route a light beam to the target.
- **通信装置 / Communication Device**：「闪光摩斯小信使」——用长短闪光拼出约定信号发给伙伴。Send a friend a message using long and short light flashes.
- **结构与功能 / Structure & Function**：「器官配配对」——把动植物器官拖到对应的功能卡上得分。Drag plant and animal parts to the matching function cards.
- **仿生 / Biomimicry**：「发明家工坊」——选一种动物特征「解锁」一个人类发明（苍耳→魔术贴）。Pick an animal feature to unlock a human invention it inspired.
- **遗传 / Heredity**：「找一家人」——把幼崽和它的父母配对，并圈出相同与不同之处。Match babies to their parents and circle what is alike and different.
- **太空 / Space Systems**：「昼夜转转盘」——转动地球看太阳东升西落，调季节滑块感受白昼长短变化。Spin the day-night dial to see sunrise and sunset, slide the season bar to compare daylight length.
