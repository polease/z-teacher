# 一年级 · 英语语言艺术 / Grade 1 · English Language Arts

> 对齐标准：美国共同核心州立标准（Common Core State Standards, Grade 1 ELA & Literacy）。本年级让学生从「认字母」走向「独立拼读与读懂简单文本」，并开始书面表达与规范用语。

## 本年级总目标 / Year Goals
一年级学生学会拼读规则、读出常见词，并能流利朗读简单文本，理解故事与信息类文章的关键细节。
First graders master phonics rules, read common words, and read simple texts fluently while understanding key details in stories and informational texts.
他们开始写观点、说明和记叙三类短文，在对话中用完整句子表达，并掌握大写、标点等基础语言规范。
They begin writing opinion, informative, and narrative pieces, speak in complete sentences during conversations, and learn foundational conventions like capitalization and punctuation.

## 1. 基础阅读技能 / Foundational Skills

### 1.1 印刷规范 / Print Concepts
- **学什么 / What**：句子的首字母大写、句末有标点；认识句子的组织特征（print concepts）。
- **掌握标准 / Mastery**：能指出一句话的开头和结尾，知道句首要大写、句末要有句号/问号/感叹号。
- **例子 / Example**：「The dog runs.」开头 T 大写，结尾有句号。

### 1.2 语音意识 / Phonological Awareness
- **学什么 / What**：区分长短元音、把音节拼成词、把口语单音节词切分成音素（distinguish long/short vowels, blend, segment phonemes）。
- **掌握标准 / Mastery**：能听辨 cap（短 a）与 cape（长 a）；把 /c/ /a/ /t/ 拼成 cat；把 dog 切成 /d/ /o/ /g/。
- **例子 / Example**：把 /s/ /u/ /n/ 拼读成 sun；把 ship 拆成 /sh/ /i/ /p/。

### 1.3 拼读：双字母组合 / Phonics: Consonant Digraphs
- **学什么 / What**：解码常见辅音双字母组合（digraphs：sh、ch、th、wh、ph、ck）。
- **掌握标准 / Mastery**：看到 ship、chin、that、duck 能正确读出。
- **例子 / Example**：sh → /sh/，读 fish、shop。

### 1.4 拼读：含 e 长元音 / Phonics: Final-e (Silent e)
- **学什么 / What**：理解词尾 e 让前面的元音发长音（final-e / magic e）。
- **掌握标准 / Mastery**：能读 cap→cape、kit→kite、hop→hope 的变化。
- **例子 / Example**：mad（短 a）→ made（长 a）。

### 1.5 拼读：元音组合 / Phonics: Vowel Teams
- **学什么 / What**：解码两个元音字母组合发一个音（vowel teams：ai、ay、ee、ea、oa、oo）。
- **掌握标准 / Mastery**：会读 rain、day、see、boat、moon 等常见组合词。
- **例子 / Example**：ee → /ē/，读 feet、tree。

### 1.6 解码两音节词 / Decoding Two-Syllable Words
- **学什么 / What**：把规则的两音节词按音节拆开来读（decode by syllables）。
- **掌握标准 / Mastery**：能把 sunset 拆成 sun·set、rabbit 拆成 rab·bit 来读。
- **例子 / Example**：napkin → nap·kin。

### 1.7 屈折词尾 / Inflectional Endings
- **学什么 / What**：读出带常见词尾的词（inflectional endings：-s、-es、-ed、-ing）。
- **掌握标准 / Mastery**：能读 cats、jumps、jumped、jumping，知道词根没变。
- **例子 / Example**：play → plays、played、playing。

### 1.8 不规则高频词 / Irregular High-Frequency Words (Sight Words)
- **学什么 / What**：整体认读不能简单拼读的高频词（sight words）。
- **掌握标准 / Mastery**：能秒认 the、of、to、you、said、was、have、what 等。
- **例子 / Example**：「said」不按拼读规则，直接记住整词。

### 1.9 流利朗读与自我纠正 / Fluency & Self-Correction
- **学什么 / What**：以恰当速度、准确、有表情地朗读，读不通时停下来重读纠正（read with accuracy, fluency, self-correct）。
- **掌握标准 / Mastery**：朗读时遇到读错能借助上下文回看并改正。
- **例子 / Example**：把「house」误读成「horse」后发现句子讲不通，回头改正。

## 2. 文学类阅读 / Reading Literature

### 2.1 提问与回答细节 / Ask & Answer About Key Details
- **学什么 / What**：就故事中的关键细节提出并回答问题（key details）。
- **掌握标准 / Mastery**：能回答「谁」「在哪」「发生了什么」「为什么」。
- **例子 / Example**：「小猪为什么盖砖房？」因为想让房子结实不被吹倒。

### 2.2 复述故事与中心寓意 / Retell Stories & Central Message
- **学什么 / What**：复述故事并说出其中的寓意或教训（retell; central message/lesson）。
- **掌握标准 / Mastery**：能按开头—中间—结尾复述，并说出故事告诉我们的道理。
- **例子 / Example**：《龟兔赛跑》寓意：坚持不懈就能成功。

### 2.3 描述角色、场景与事件 / Describe Characters, Settings & Events
- **学什么 / What**：用关键细节描述故事中的人物、地点和事件（characters, settings, major events）。
- **掌握标准 / Mastery**：能说出主角是谁、故事发生在哪、发生了哪些大事。
- **例子 / Example**：「故事发生在森林里，主角是一只勇敢的小兔。」

### 2.4 理解感受与五感词 / Words That Appeal to Senses & Feelings
- **学什么 / What**：理解描写感受和调动五感（看/听/闻/尝/触）的词语（sensory and feeling words）。
- **掌握标准 / Mastery**：能找出表示开心、害怕或描写声音、味道的词。
- **例子 / Example**：「香脆的饼干」「轰隆隆的雷声」分别调动味觉和听觉。

### 2.5 分清谁在讲故事 / Identify Who Is Telling the Story
- **学什么 / What**：辨别故事中各处是哪个角色或叙述者在说话（narrator / point of view）。
- **掌握标准 / Mastery**：能区分对话由哪个人物说出，知道叙述者与角色的不同。
- **例子 / Example**：引号里的话是兔子说的，引号外是讲述者在说。

### 2.6 比较不同角色的经历 / Compare Characters' Experiences
- **学什么 / What**：比较故事中不同角色的经历和遭遇（compare adventures/experiences）。
- **掌握标准 / Mastery**：能说出两个角色做法或结果的异同。
- **例子 / Example**：盖草房的小猪和盖砖房的小猪结果不同。

## 3. 信息类阅读 / Reading Informational

### 3.1 主旨与关键细节 / Main Topic & Key Details
- **学什么 / What**：找出文章主旨并复述关键细节（main topic, key details）。
- **掌握标准 / Mastery**：能用一句话说出文章讲什么，再举出支持的细节。
- **例子 / Example**：主旨「青蛙的生命周期」，细节：卵→蝌蚪→青蛙。

### 3.2 联系文中的人事信息 / Connect Individuals, Events, Ideas
- **学什么 / What**：说出文中两个人、事件、想法或信息之间的联系（make connections）。
- **掌握标准 / Mastery**：能说明「因为……所以……」的关系。
- **例子 / Example**：因为下雨，所以植物长得更快。

### 3.3 文本特征 / Text Features
- **学什么 / What**：使用标题、目录、词汇表等帮助找信息（headings, tables of contents, glossaries）。
- **掌握标准 / Mastery**：知道用目录找章节、用词汇表查生词。
- **例子 / Example**：想了解「鲸鱼」，先在目录里找到对应页码。

### 3.4 用插图理解 / Use Illustrations to Understand
- **学什么 / What**：借助图片和图说理解文章内容（use illustrations and details）。
- **掌握标准 / Mastery**：能从图中读出文字没明说的信息。
- **例子 / Example**：看蝴蝶图理解「翅膀有对称花纹」。

### 3.5 作者给出的理由 / Author's Reasons
- **学什么 / What**：找出作者用来支持观点的理由（reasons that support points）。
- **掌握标准 / Mastery**：能说出作者为什么这么认为。
- **例子 / Example**：作者说「该多运动」，理由是「运动让身体更健康」。

## 4. 写作 / Writing

### 4.1 观点类写作 / Opinion Writing
- **学什么 / What**：写出自己的看法、给出至少一个理由并有结尾（opinion piece）。
- **掌握标准 / Mastery**：能写「我喜欢……，因为……」并加一句收尾。
- **例子 / Example**：「我最喜欢狗，因为它会陪我玩。狗是最好的宠物。」

### 4.2 说明类写作 / Informative / Explanatory Writing
- **学什么 / What**：介绍一个主题、提供事实并有结尾（informative/explanatory text）。
- **掌握标准 / Mastery**：能命名话题、写出几条事实、加结束句。
- **例子 / Example**：「蝴蝶有翅膀。它们吃花蜜。蝴蝶很美。」

### 4.3 记叙类写作（按顺序讲事件） / Narrative Writing
- **学什么 / What**：按时间顺序讲两件或更多有联系的事，加入细节和结尾（narrative; sequenced events）。
- **掌握标准 / Mastery**：会用 first、then、next、last 等词把事件串起来。
- **例子 / Example**：「先去公园，然后荡秋千，最后吃了冰淇淋。」

### 4.4 在帮助下补充细节与修改 / Add Details with Guidance
- **学什么 / What**：在大人或同伴帮助下补充细节、回应建议并修改（add details, revise with support）。
- **掌握标准 / Mastery**：能根据提问加进更多描述把文章写得更清楚。
- **例子 / Example**：老师问「狗长什么样？」学生补上「它是一只棕色的小狗」。

## 5. 口语与倾听 / Speaking & Listening

### 5.1 合作对话规则 / Rules for Collaborative Conversations
- **学什么 / What**：遵守对话规则——轮流发言、专心倾听、紧扣话题（conversation rules）。
- **掌握标准 / Mastery**：能等别人说完再说、不打断、接着别人的话题往下说。
- **例子 / Example**：小组讨论时举手轮流分享想法。

### 5.2 就细节提问与回答 / Ask & Answer Questions About Details
- **学什么 / What**：就听到或读到的内容提问、回答，以弄清不懂的地方（ask and answer to clarify）。
- **掌握标准 / Mastery**：听完后能问出有意义的问题并回答别人的提问。
- **例子 / Example**：听完故事问「后来小狗去哪了？」

### 5.3 描述人事物 / Describe People, Places, Things, Events
- **学什么 / What**：描述熟悉的人、地点、事物和事件并表达想法感受（describe with details）。
- **掌握标准 / Mastery**：能加上相关细节把描述说清楚。
- **例子 / Example**：「我的奶奶很温柔，她会做好吃的饺子。」

### 5.4 用完整句子表达 / Produce Complete Sentences
- **学什么 / What**：根据情境用完整句子表达（complete sentences）。
- **掌握标准 / Mastery**：回答问题时说完整句而非单个词。
- **例子 / Example**：不只说「红色」，而说「我最喜欢的颜色是红色。」

## 6. 语言规范 / Language

### 6.1 大写规则 / Capitalization
- **学什么 / What**：日期、人名和单词「I」要大写（capitalize dates, names, I）。
- **掌握标准 / Mastery**：会写 Monday、June、Tom、I。
- **例子 / Example**：「Tom and I play on Friday.」

### 6.2 标点与逗号 / Punctuation & Commas
- **学什么 / What**：句末用正确标点，日期和并列项中用逗号（end punctuation; commas in dates and series）。
- **掌握标准 / Mastery**：陈述句用句号、问句用问号、感叹句用感叹号；写 June 14, 2026；写 red, blue, and green。
- **例子 / Example**：「I like apples, bananas, and grapes.」

### 6.3 词类 / Parts of Speech
- **学什么 / What**：认识并使用名词、动词、形容词、代词、介词、连词（nouns, verbs, adjectives, pronouns, prepositions, conjunctions）。
- **掌握标准 / Mastery**：能在句中找出名词和动词，用形容词描述，用 and/but 连接。
- **例子 / Example**：「The big dog runs and jumps.」big 是形容词，runs/jumps 是动词。

### 6.4 复数名词 / Plural Nouns
- **学什么 / What**：用 -s、-es 构成常见复数（regular plural nouns）。
- **掌握标准 / Mastery**：会写 cat→cats、box→boxes。
- **例子 / Example**：one dog → two dogs。

### 6.5 用拼音法拼写生词 / Spell Untaught Words Phonetically
- **学什么 / What**：依据语音和拼写规则尝试拼写没学过的词（phonetic / inventive spelling）。
- **掌握标准 / Mastery**：能把听到的音对应到合理的字母组合。
- **例子 / Example**：把 lake 拼成 lake 或合理近似如 laik。

### 6.6 词义关系：归类与多义 / Word Relationships: Categories & Meaning
- **学什么 / What**：把词按概念归类、理解常见词的细微差别与多义（sort into categories, word meanings）。
- **掌握标准 / Mastery**：能把词分到「动物」「食物」等类别，区分 look、peek、stare 的程度。
- **例子 / Example**：把 cat、dog、cow 归为「动物」；duck 既是名词也是动词。

## 游戏化玩法建议 / Gamification Hooks
- **拼读 / Phonics**：「拼音魔法屋」——把 final-e 拖到词尾，元音立刻从短音「变身」长音并播放发音。Drag a magic-e to the end of a word and watch the vowel transform to its long sound.
- **语音意识 / Phonological Awareness**：「音素接龙泡泡」——把 /c/ /a/ /t/ 三个音泡泡合并成 cat 才能过关。Merge sound bubbles to blend phonemes into a word.
- **高频词 / Sight Words**：「秒认大挑战」——闪现高频词，在词消失前点对得分。Flash sight words and tap before they fade for points.
- **文学阅读 / Reading Literature**：「故事顺序拼图」——把开头/中间/结尾的画面卡按顺序排好复述故事。Arrange beginning-middle-end picture cards to retell the story.
- **信息阅读 / Reading Informational**：「目录寻宝」——根据问题用目录或词汇表跳到正确页找答案。Use the table of contents or glossary to jump to the right page and find answers.
- **写作 / Writing**：「句子搭搭乐」——拖动词块拼出完整句，再用提问按钮添加细节升级句子。Drag word blocks to build a complete sentence, then tap prompts to add details.
- **口语与倾听 / Speaking & Listening**：「完整句对讲机」——录下完整句回答，AI 检测是否成句并给星。Record a complete-sentence answer; the app checks completeness and awards stars.
- **语言规范 / Language**：「大写小写抓抓乐」——句中该大写的字母会闪光，点对了变金色。Tap the letters that should be capitalized; correct ones turn gold.
