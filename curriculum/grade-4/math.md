# 四年级 · 数学 / Grade 4 · Math

> 对齐标准：Common Core State Standards for Mathematics, Grade 4 (CCSS-M G4)。本年级聚焦多位数乘除、分数的等值与运算、以及几何与测量的系统理解。

## 本年级总目标 / Year Goals
四年级学生能流利地进行多位数加减、用多种策略完成乘除运算，并理解乘法是「倍数比较」。
Fourth graders fluently add and subtract multi-digit numbers, multiply and divide using multiple strategies, and understand multiplication as a comparison.
他们建立分数的等值与运算概念，并把分数与小数联系起来；同时学会用公式求面积周长、用量角器测角、对二维图形分类。
They build equivalence and operations with fractions, connect fractions to decimals, and learn to find area and perimeter, measure angles with a protractor, and classify two-dimensional figures.

## 1. 运算与代数思维 / Operations & Algebraic Thinking

### 1.1 乘法是倍数比较 / Multiplication as Comparison
- **学什么 / What**：把乘法算式理解为「几倍」的比较（multiplicative comparison），区分「多几」(additive) 与「多几倍」(multiplicative)。
- **掌握标准 / Mastery**：能把语句「35 是 5 的 7 倍」写成 35 = 5 × 7，并能反向把算式说成倍数语句。
- **例子 / Example**：小红有 3 个贴纸，小明有她的 4 倍，列式 3 × 4 = 12。

### 1.2 用乘除法解倍数应用题 / Word Problems with Multiplicative Comparison
- **学什么 / What**：用乘法或除法解决「倍数」类应用题，并用画图或方程表示未知量。
- **掌握标准 / Mastery**：能区分倍数比较题与加法比较题，并选对运算。
- **例子 / Example**：一本书 24 页是另一本的 3 倍，另一本多少页？列式 24 ÷ 3 = 8。

### 1.3 多步应用题与未知量 / Multistep Word Problems
- **学什么 / What**：用四则运算解多步整数应用题，用字母表示未知量（含余数的解释）。
- **掌握标准 / Mastery**：能列出含变量的方程并求解，能正确解释余数的含义。
- **例子 / Example**：26 名学生每车坐 4 人，需要几辆车？26 ÷ 4 = 6 余 2，因此需 7 辆车。

### 1.4 估算判断合理性 / Estimation & Reasonableness
- **学什么 / What**：用心算和估算策略（含取整 rounding）判断答案是否合理。
- **掌握标准 / Mastery**：能在计算前估算范围，并用估算检查结果。
- **例子 / Example**：298 + 405，估算约 300 + 400 = 700，因此答案约 700。

### 1.5 因数与倍数 / Factors & Multiples
- **学什么 / What**：在 1–100 内求一个数的所有因数对（factor pairs）、判断倍数、识别质数 (prime) 与合数 (composite)。
- **掌握标准 / Mastery**：能列出某数全部因数，判断给定数是否是某数的倍数，判断 100 以内某数是质数还是合数。
- **例子 / Example**：24 的因数有 1, 2, 3, 4, 6, 8, 12, 24；17 是质数。

### 1.6 生成与分析规律 / Generate & Analyze Patterns
- **学什么 / What**：根据给定规则生成数或形状的规律 (pattern)，并发现规则中未明说的特征。
- **掌握标准 / Mastery**：能延续规律并描述其隐藏属性。
- **例子 / Example**：规则「加 3，从 1 开始」得 1, 4, 7, 10…，可发现这些数交替出现奇偶。

## 2. 十进制数与运算 / Number & Operations in Base Ten

### 2.1 位值关系 / Place Value Relationships
- **学什么 / What**：理解多位数中某位上的数字代表的值是它右边一位的 10 倍。
- **掌握标准 / Mastery**：能说明同一数字在不同数位上代表的值的 10 倍关系。
- **例子 / Example**：700 ÷ 70 = 10，说明百位的 7 是十位 7 的 10 倍。

### 2.2 读写多位数 / Read & Write Multi-Digit Numbers
- **学什么 / What**：用基于位值的方式读写最多到千万级别的整数，掌握数字形式 (base-ten numerals)、名称 (number names)、展开式 (expanded form)。
- **掌握标准 / Mastery**：能在三种表示之间自由转换。
- **例子 / Example**：3,047 = 3000 + 40 + 7，读作「三千零四十七」。

### 2.3 比较与四舍五入 / Compare & Round
- **学什么 / What**：用 >、=、< 比较两个多位数；把多位数四舍五入到任意数位。
- **掌握标准 / Mastery**：能把数四舍五入到指定数位并解释依据。
- **例子 / Example**：4,872 四舍五入到百位是 4,900。

### 2.4 多位数加减 / Multi-Digit Addition & Subtraction
- **学什么 / What**：用标准算法 (standard algorithm) 熟练计算多位数加减。
- **掌握标准 / Mastery**：能正确处理进位与借位，结果准确。
- **例子 / Example**：5,372 − 1,896 = 3,476。

### 2.5 多位数乘法 / Multi-Digit Multiplication
- **学什么 / What**：计算最多四位数乘一位数、两位数乘两位数；用策略、面积模型 (area model)、位值与运算性质来计算并解释。
- **掌握标准 / Mastery**：能用面积模型或部分积解释计算过程。
- **例子 / Example**：23 × 14，用面积模型拆为 (20+3)(10+4) = 200+80+30+12 = 322。

### 2.6 多位数除法 / Multi-Digit Division
- **学什么 / What**：最多四位数除以一位数（含余数），用位值、运算性质或矩形模型解释。
- **掌握标准 / Mastery**：能正确求商与余数并用乘法验算。
- **例子 / Example**：738 ÷ 6 = 123，验算 123 × 6 = 738。

## 3. 分数 / Number & Operations—Fractions

### 3.1 等值分数 / Equivalent Fractions
- **学什么 / What**：理解 a/b = (n×a)/(n×b)，用图形模型识别和生成等值分数 (equivalent fractions)。
- **掌握标准 / Mastery**：能写出某分数的等值分数并用模型说明。
- **例子 / Example**：1/2 = 2/4 = 3/6。

### 3.2 比较分数 / Compare Fractions
- **学什么 / What**：用通分或基准量（如 1/2、1）比较异分子异分母分数。
- **掌握标准 / Mastery**：能比较两个分数大小并用 >、=、< 记录，理解只有同一整体的分数才能直接比较。
- **例子 / Example**：3/8 < 1/2，因为 1/2 = 4/8。

### 3.3 同分母分数加减 / Add & Subtract Fractions
- **学什么 / What**：把分数理解为单位分数之和，进行同分母分数与带分数 (mixed numbers) 的加减，并能分解分数。
- **掌握标准 / Mastery**：能把 7/8 分解为 1/8+1/8+…，并完成带分数加减。
- **例子 / Example**：3 1/4 + 2 2/4 = 5 3/4。

### 3.4 分数乘整数 / Multiply Fraction by Whole Number
- **学什么 / What**：把 n × (a/b) 理解为 (n×a)/b，并用其解应用题。
- **掌握标准 / Mastery**：能列式并用模型解释分数乘整数。
- **例子 / Example**：3 × 2/5 = 6/5 = 1 1/5。

### 3.5 分数与小数 / Fractions to Decimals
- **学什么 / What**：把分母为 10 和 100 的分数写成小数 (decimals)，并理解 10 与 100 之间的等值关系。
- **掌握标准 / Mastery**：能在分数与小数间转换，如 3/10 = 30/100 = 0.30。
- **例子 / Example**：62/100 = 0.62。

### 3.6 比较小数 / Compare Decimals
- **学什么 / What**：比较到百分位 (hundredths) 的两个小数，理解只有指同一整体时比较才有意义。
- **掌握标准 / Mastery**：能用 >、=、< 比较小数并用模型验证。
- **例子 / Example**：0.7 > 0.45。

## 4. 测量与数据 / Measurement & Data

### 4.1 单位换算 / Unit Conversions
- **学什么 / What**：在同一度量制度内把大单位换成小单位（如 km→m、kg→g、hr→min）。
- **掌握标准 / Mastery**：能制作单位换算表并完成换算。
- **例子 / Example**：3 km = 3000 m。

### 4.2 测量应用题 / Measurement Word Problems
- **学什么 / What**：解决涉及距离、时间、容积、质量、金钱的应用题（含分数与小数）。
- **掌握标准 / Mastery**：能用图示（如数轴）表示并求解。
- **例子 / Example**：一瓶水 1.5 L，喝掉 0.75 L，还剩 0.75 L。

### 4.3 面积与周长 / Area & Perimeter
- **学什么 / What**：在实际问题中应用矩形的面积公式 A = l×w 与周长公式 P = 2(l+w)。
- **掌握标准 / Mastery**：能由已知量求未知边长或面积/周长。
- **例子 / Example**：长 8 宽 3 的矩形面积 24，周长 22。

### 4.4 角的概念与测量 / Angles & Measurement
- **学什么 / What**：把角看作圆的几分之几（1° 是把圆分成 360 份的一份），用量角器 (protractor) 测量与画角。
- **掌握标准 / Mastery**：能用量角器准确测量并画出指定度数的角。
- **例子 / Example**：直角是 90°，是整圆的 1/4。

### 4.5 角的可加性 / Angle Addition
- **学什么 / What**：理解一个大角可被分成若干相邻小角，整体角度等于各部分之和；用此解未知角应用题。
- **掌握标准 / Mastery**：能用加减法求被分割角中的未知角。
- **例子 / Example**：一个 120° 的角被分成 70° 与未知角，未知角为 50°。

### 4.6 含分数的折线图 / Line Plots with Fractions
- **学什么 / What**：制作并解读以 1/2、1/4、1/8 为单位的折线图 (line plot)，用其解加减应用题。
- **掌握标准 / Mastery**：能从折线图读取数据并计算差值。
- **例子 / Example**：用折线图记录铅笔长度并求最长与最短之差。

## 5. 几何 / Geometry

### 5.1 点线角的要素 / Points, Lines & Angles
- **学什么 / What**：认识并画出点、线、线段、射线、角（锐角/钝角/直角）、垂直线 (perpendicular) 与平行线 (parallel)。
- **掌握标准 / Mastery**：能在图形中识别并标注这些要素。
- **例子 / Example**：在字母 L 中找到一个直角与两条垂直线段。

### 5.2 按线与角分类图形 / Classify Figures by Lines & Angles
- **学什么 / What**：根据是否存在平行/垂直线、特定角度来分类二维图形。
- **掌握标准 / Mastery**：能依据属性把图形归类（如正方形是有四个直角的矩形）。
- **例子 / Example**：梯形至少有一组平行边。

### 5.3 直角三角形 / Right Triangles
- **学什么 / What**：识别含一个直角的三角形 (right triangle)。
- **掌握标准 / Mastery**：能从一组三角形中挑出直角三角形。
- **例子 / Example**：三角板中的三角形含一个 90° 角。

### 5.4 对称轴 / Lines of Symmetry
- **学什么 / What**：识别并画出二维图形的对称轴 (line of symmetry)。
- **掌握标准 / Mastery**：能判断图形是否对称并画出所有对称轴。
- **例子 / Example**：正方形有 4 条对称轴，蝴蝶图形有 1 条。

## 游戏化玩法建议 / Gamification Hooks
- **运算与代数思维 / Operations & Algebraic Thinking**：「质数猎人」关卡——屏幕落下数字方块，玩家只射击质数得分，合数射错扣血，自然练习质数/合数判断。
- **十进制数与运算 / Number & Operations in Base Ten**：「面积模型工坊」——拖动方格拼出两位数乘两位数的面积模型，正确分块即点亮，强化部分积概念。
- **分数 / Fractions**：「披萨等值大作战」——把不同切法的披萨拖到天平两端，使两边等值（如 1/2 vs 2/4）才能过关。
- **测量与数据 / Measurement & Data**：「量角器神射手」——用虚拟量角器把炮口转到题目指定角度发射击中目标，练习读量角器。
- **几何 / Geometry**：「对称镜像迷宫」——玩家画出对称轴使图形左右合拢解锁机关，错误对称轴会触发陷阱。
