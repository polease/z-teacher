# 四年级 · 数学 / Grade 4 · Mathematics

> 对齐标准：美国共同核心州立标准（Common Core State Standards, CCSS-Math, Grade 4）。本年级把乘法拓展为「倍数比较」，掌握多位数四则运算与分数运算，并初步建立几何与测量概念。

## 本年级总目标 / Year Goals
四年级学生要能流利完成多位数加减、四位数乘一位数和两位数乘两位数、四位数除以一位数（含余数），并解决多步实际问题。
Grade 4 students fluently add and subtract multi-digit numbers, multiply up to four-digit by one-digit and two-digit by two-digit numbers, and divide four-digit numbers by one-digit numbers with remainders, while solving multi-step word problems.
学生要理解等值分数、比较分数与小数，并掌握分数的加减、分数乘整数。
Students understand equivalent fractions, compare fractions and decimals, and add/subtract fractions and multiply fractions by whole numbers.
学生还要会换算度量单位、用公式求面积周长、用量角器测量角，并按线与角给图形分类。
Students convert measurement units, use area and perimeter formulas, measure angles with a protractor, and classify shapes by lines and angles.

## 1. 运算与代数思维 / Operations & Algebraic Thinking

### 1.1 乘法作为倍数比较 / Multiplicative Comparison
- **学什么 / What**：把乘法理解为「比较倍数」（multiplicative comparison），如 35 是 5 的 7 倍，可写成 35 = 5 × 7。
- **掌握标准 / Mastery**：能用乘法方程表示「a 是 b 的 n 倍」，并区分倍数比较与加法比较（additive comparison）。
- **例子 / Example**：哥哥有 24 块积木，是弟弟的 3 倍，弟弟有几块？写成 24 = 3 × □，得 8 块。

### 1.2 倍数比较类应用题 / Word Problems with Comparison
- **学什么 / What**：用乘除法解「相差几倍」的实际问题（comparison word problems）。
- **掌握标准 / Mastery**：能判断该用乘法还是除法，并写出含未知数的方程。
- **例子 / Example**：红绳长 6 米，蓝绳是它的 4 倍，蓝绳多长？6 × 4 = 24 米。

### 1.3 多步四则应用题 / Multi-Step Word Problems
- **学什么 / What**：解需要多步、用到加减乘除（four operations）的应用题。
- **掌握标准 / Mastery**：能列出包含未知量字母（variable）的方程并求解。
- **例子 / Example**：买 3 盒铅笔每盒 12 支，用掉 8 支，还剩几支？3 × 12 − 8 = 28 支。

### 1.4 解释除法余数 / Interpreting Remainders
- **学什么 / What**：根据题意解释余数（remainder）该进位、舍去还是单独保留。
- **掌握标准 / Mastery**：能说明同一个余数在不同情境下的含义。
- **例子 / Example**：26 人坐每车 4 座的车，要 7 辆车（26 ÷ 4 = 6 余 2，余下 2 人也需要一辆）。

### 1.5 用估算判断合理性 / Estimation & Reasonableness
- **学什么 / What**：用估算与取整（rounding）判断答案是否合理（reasonableness），运用心算策略。
- **掌握标准 / Mastery**：能在计算前后用估算检验结果数量级是否正确。
- **例子 / Example**：387 + 612 约等于 400 + 600 = 1000，所以答案应接近 1000。

### 1.6 因数与倍数 / Factors & Multiples
- **学什么 / What**：找出 1–100 内某数的全部因数（factors），并判断某数是否是给定一位数的倍数（multiple）。
- **掌握标准 / Mastery**：能列出因数对，并用倍数关系做判断。
- **例子 / Example**：24 的因数有 1, 2, 3, 4, 6, 8, 12, 24；24 是 6 的倍数。

### 1.7 质数与合数 / Prime & Composite Numbers
- **学什么 / What**：判断 1–100 内的数是质数（prime）还是合数（composite）。
- **掌握标准 / Mastery**：能用因数个数说明判断理由。
- **例子 / Example**：7 只有 1 和 7 两个因数，是质数；9 有 1、3、9，是合数。

### 1.8 生成与分析规律 / Generating & Analyzing Patterns
- **学什么 / What**：按给定规则生成数字或图形规律（pattern），并发现规则没有明说的特征。
- **掌握标准 / Mastery**：能延续规律并解释隐含特征。
- **例子 / Example**：规则「加 3 起始 1」生成 1, 4, 7, 10…，可发现结果总是奇偶交替之外，个位循环 1,4,7,0。

## 2. 十进制数与运算 / Number & Operations in Base Ten

### 2.1 位值关系 / Place Value Relationships
- **学什么 / What**：理解多位数中左边一位的值是右边一位的 10 倍（place value）。
- **掌握标准 / Mastery**：能说明某数字在不同数位上代表的值。
- **例子 / Example**：700 中的 7 是 70 中的 7 的 10 倍。

### 2.2 读写多位数 / Reading & Writing Multi-Digit Numbers
- **学什么 / What**：用位值、数字名称、展开式（expanded form）读写多位数。
- **掌握标准 / Mastery**：能在标准式、名称、展开式三种形式间互相转换。
- **例子 / Example**：3,452 = 3,000 + 400 + 50 + 2，读作「三千四百五十二」。

### 2.3 比较多位数 / Comparing Multi-Digit Numbers
- **学什么 / What**：用 >、=、< 比较两个多位数（compare）。
- **掌握标准 / Mastery**：能从最高位起逐位比较并下结论。
- **例子 / Example**：4,532 > 4,498，因为百位 5 > 4。

### 2.4 四舍五入 / Rounding
- **学什么 / What**：把多位数四舍五入（round）到任意数位。
- **掌握标准 / Mastery**：能按指定数位正确进位或舍去。
- **例子 / Example**：3,650 四舍五入到百位是 3,700。

### 2.5 多位数加减 / Multi-Digit Addition & Subtraction
- **学什么 / What**：用标准算法（standard algorithm）熟练计算多位数加减法。
- **掌握标准 / Mastery**：能正确处理进位与借位并保持流利。
- **例子 / Example**：5,204 − 1,876 = 3,328。

### 2.6 多位数乘一位数 / Multiplying by One Digit
- **学什么 / What**：用位值与运算性质，计算最多四位数乘一位数（multiply）。
- **掌握标准 / Mastery**：能用方程、矩形阵列或面积模型表示并求解。
- **例子 / Example**：1,234 × 4 = 4,936。

### 2.7 两位数乘两位数 / Two-Digit by Two-Digit
- **学什么 / What**：用面积模型（area model）或部分积计算两位数乘两位数。
- **掌握标准 / Mastery**：能画出面积模型并把各部分相加得出结果。
- **例子 / Example**：23 × 14 = 20×14 + 3×14 = 280 + 42 = 322。

### 2.8 多位数除以一位数 / Dividing by One Digit
- **学什么 / What**：用位值与运算性质，计算最多四位数除以一位数（含余数）。
- **掌握标准 / Mastery**：能用方程、阵列或面积模型说明商与余数。
- **例子 / Example**：738 ÷ 5 = 147 余 3。

## 3. 分数 / Number & Operations—Fractions

### 3.1 等值分数 / Equivalent Fractions
- **学什么 / What**：用分子分母同乘一个数生成等值分数（equivalent fractions）。
- **掌握标准 / Mastery**：能用面积模型或数线说明为什么两个分数相等。
- **例子 / Example**：1/2 = 2/4 = 3/6。

### 3.2 比较异分母分数 / Comparing Fractions
- **学什么 / What**：用基准分数（benchmark，如 1/2）或通分比较分子分母都不同的分数。
- **掌握标准 / Mastery**：能用 >、=、< 比较并说明理由。
- **例子 / Example**：3/8 < 1/2，因为 4/8 才等于 1/2。

### 3.3 同分母分数加减 / Adding & Subtracting Fractions
- **学什么 / What**：把分数看成单位分数之和，进行同分母（like denominators）加减。
- **掌握标准 / Mastery**：能把分数分解成多种和的形式。
- **例子 / Example**：3/8 = 1/8 + 1/8 + 1/8；5/8 − 2/8 = 3/8。

### 3.4 带分数加减 / Mixed Numbers
- **学什么 / What**：对带分数（mixed numbers）做同分母加减，并与假分数互换。
- **掌握标准 / Mastery**：能在带分数与假分数之间转换并计算。
- **例子 / Example**：2 1/4 + 1 2/4 = 3 3/4。

### 3.5 分数乘整数 / Multiplying Fractions by Whole Numbers
- **学什么 / What**：把分数乘整数理解为重复相加（multiply by whole number）。
- **掌握标准 / Mastery**：能列方程并解相关应用题。
- **例子 / Example**：5 × 2/3 = 10/3 = 3 1/3。

### 3.6 十进分数转小数 / Decimals from Fractions
- **学什么 / What**：把分母为 10 或 100 的分数写成小数（decimal）。
- **掌握标准 / Mastery**：能在十分位、百分位的分数与小数间转换。
- **例子 / Example**：62/100 = 0.62；3/10 = 0.3。

### 3.7 比较小数 / Comparing Decimals
- **学什么 / What**：比较到百分位（hundredths）的小数。
- **掌握标准 / Mastery**：能用 >、=、< 比较小数并说明依据。
- **例子 / Example**：0.45 < 0.5，因为 0.50 大于 0.45。

## 4. 测量与数据 / Measurement & Data

### 4.1 单位换算 / Unit Conversion
- **学什么 / What**：在同一度量制度内把大单位换成小单位（convert units）。
- **掌握标准 / Mastery**：能列出换算表并完成换算。
- **例子 / Example**：1 千米 = 1000 米；3 千米 = 3000 米。

### 4.2 测量应用题 / Measurement Word Problems
- **学什么 / What**：解关于距离、时间、容积、质量、钱的应用题（含分数小数）。
- **掌握标准 / Mastery**：能在解题中正确换算并用图示表示。
- **例子 / Example**：一瓶水 1.5 升，喝掉 0.75 升，还剩 0.75 升。

### 4.3 面积与周长 / Area & Perimeter
- **学什么 / What**：用公式求矩形的面积（area）与周长（perimeter）。
- **掌握标准 / Mastery**：能在已知部分量时求未知边长。
- **例子 / Example**：长 6 宽 4 的矩形，面积 = 24，周长 = 20。

### 4.4 用量角器测角 / Measuring Angles
- **学什么 / What**：理解角是圆的几分之几，用量角器（protractor）测量与画角。
- **掌握标准 / Mastery**：能测量与绘制指定度数的角。
- **例子 / Example**：直角是 90°，是整圆 360° 的 1/4。

### 4.5 角的可加性 / Additive Angles
- **学什么 / What**：理解角可以相加（angle addition），整体角等于各部分角之和。
- **掌握标准 / Mastery**：能用减法求出被分割角中的未知角。
- **例子 / Example**：一个 80° 的角被分成 30° 和 □，则 □ = 50°。

### 4.6 含分数的折线图 / Line Plots
- **学什么 / What**：制作并解读以分数为单位的折线图（line plot）。
- **掌握标准 / Mastery**：能用折线图数据做加减运算。
- **例子 / Example**：把多段长度 1/8、2/8、5/8 英寸的数据画在折线图上并求最长与最短之差。

## 5. 几何 / Geometry

### 5.1 点线角基础 / Points, Lines & Angles
- **学什么 / What**：认识并画出点（point）、线段、直线、射线（ray）、角，以及垂直（perpendicular）与平行（parallel）线。
- **掌握标准 / Mastery**：能在图形中识别并命名这些元素。
- **例子 / Example**：正方形相邻两边垂直，对边平行。

### 5.2 按线与角分类图形 / Classifying Shapes
- **学什么 / What**：根据平行/垂直线及角的类型给二维图形分类（classify）。
- **掌握标准 / Mastery**：能说明分类依据。
- **例子 / Example**：有一组平行边的四边形是梯形。

### 5.3 识别直角三角形 / Right Triangles
- **学什么 / What**：识别含一个直角（right angle）的三角形。
- **掌握标准 / Mastery**：能从一组三角形中挑出直角三角形。
- **例子 / Example**：含 90° 角的三角形是直角三角形。

### 5.4 对称轴 / Lines of Symmetry
- **学什么 / What**：识别并画出二维图形的对称轴（line of symmetry）。
- **掌握标准 / Mastery**：能判断图形有几条对称轴。
- **例子 / Example**：正方形有 4 条对称轴，等边三角形有 3 条。

## 游戏化玩法建议 / Gamification Hooks
- **运算与代数思维**：「倍数擂台」关卡，给出「a 是 b 的几倍」选择题，连对加速积分；解多步应用题时把余数情境做成「装车/装箱」小游戏让玩家选择进位或舍去。
- **十进制数与运算**：「位值滑块」把数字拖到正确数位，错位扣分；面积模型乘法做成「拼方块」拖拽两位数乘法的部分积。
- **分数**：「分数披萨」拖动切片验证等值分数；「基准跷跷板」把两个分数放到天平两端，与 1/2 比较看哪端更重。
- **测量与数据**：「量角器射击」用旋转量角器对准目标角度发射；单位换算做成「换算齿轮」拼图。
- **几何**：「图形分拣机」按平行、垂直、角类型把图形投入对应通道；「镜像对称」让玩家画出图形缺失的对称另一半。
