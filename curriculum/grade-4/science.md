# 四年级 · 科学 / Grade 4 · Science

> 对齐标准：Next Generation Science Standards, Grade 4 (NGSS G4)。本年级围绕能量、波、动植物的结构与信息处理、以及地球历史与人类影响展开。

## 本年级总目标 / Year Goals
四年级学生通过观察与实验理解能量的转移与转化，用波的模型解释信息传递。
Fourth graders use observation and investigation to understand the transfer and conversion of energy and use wave models to explain how information travels.
他们研究动植物结构如何支持生存，并用岩层、化石、风化侵蚀的证据说明地球随时间变化及人类的影响。
They study how structures support survival and use evidence from rock layers, fossils, weathering, and erosion to explain Earth's change over time and human impact.

## 1. 能量 / Energy (4-PS3)

### 1.1 能量与速度 / Energy & Speed of Objects
- **学什么 / What**：理解运动物体的能量与其速度有关，速度越快能量越大 (kinetic energy)。
- **掌握标准 / Mastery**：能用观察论证更快的物体拥有更多能量。
- **例子 / Example**：从更高坡道滚下的小车撞得更远，说明它能量更大。

### 1.2 能量的转移 / Energy Transfer
- **学什么 / What**：能量可通过碰撞 (collisions)、声 (sound)、光 (light)、热 (heat) 与电流 (electric currents) 从一处转移到另一处。
- **掌握标准 / Mastery**：能识别并描述几种能量转移方式。
- **例子 / Example**：电池经导线把能量送到小灯泡使其发光发热。

### 1.3 能量的转化 / Energy Conversion
- **学什么 / What**：能量可以从一种形式转化 (convert) 为另一种形式，如电能变成光和热。
- **掌握标准 / Mastery**：能在装置中追踪能量形式的变化。
- **例子 / Example**：手电筒把电能转化为光能。

### 1.4 设计能量转化装置 / Design an Energy-Conversion Device
- **学什么 / What**：应用科学概念设计、测试并改进一个把能量从一种形式转化为另一种形式的装置。
- **掌握标准 / Mastery**：能提出方案、测试并依据结果改进。
- **例子 / Example**：设计一个风车把风的运动能转化为提升小物的能量。

## 2. 波 / Waves (4-PS4)

### 2.1 波的模型 / Model of a Wave
- **学什么 / What**：用振幅 (amplitude) 与波长 (wavelength) 描述波的模型，理解波有规律地起伏。
- **掌握标准 / Mastery**：能画出并标注波的振幅与波长。
- **例子 / Example**：用绳子上下抖动制造可见波形。

### 2.2 波使物体运动 / Waves Cause Motion
- **学什么 / What**：理解波能使物体运动 (waves can make objects move)，因为波携带能量。
- **掌握标准 / Mastery**：能举例说明波传递能量引起运动。
- **例子 / Example**：水面波使漂浮的小船上下浮动。

### 2.3 用模式传递信息 / Patterns to Transfer Information
- **学什么 / What**：生成并比较多种用模式 (patterns) 传递信息的方案，理解数字化信号 (digitized signals) 如何编码信息。
- **掌握标准 / Mastery**：能设计一种用模式（光/声/符号）传信息的方法。
- **例子 / Example**：用长短闪光（类似摩尔斯电码）传递字母。

## 3. 结构功能与信息处理 / Structure, Function & Information Processing (4-LS1)

### 3.1 内外结构支持生存 / Internal & External Structures
- **学什么 / What**：论证植物与动物的内部结构 (internal) 与外部结构 (external) 如何支持其生存、生长、行为与繁殖。
- **掌握标准 / Mastery**：能把结构与其功能配对说明。
- **例子 / Example**：仙人掌的刺减少水分流失帮助在沙漠生存。

### 3.2 感官接收信息 / Sensing Information
- **学什么 / What**：动物通过感官 (senses) 接收来自环境的不同信息。
- **掌握标准 / Mastery**：能说明各感官接收何种信息。
- **例子 / Example**：眼睛接收光信息，耳朵接收声信息。

### 3.3 大脑处理与作出反应 / Brain Processing & Response
- **学什么 / What**：信息经感官传到大脑 (brain) 处理，再引导动物作出即时反应或储存为记忆。
- **掌握标准 / Mastery**：能描述「感官—大脑—反应」的信息流。
- **例子 / Example**：手碰到热物，感觉传到大脑，立即缩回。

## 4. 地球的历史与系统 / Earth's History & Systems (4-ESS1, 4-ESS2, 4-ESS3)

### 4.1 岩层与化石作为证据 / Rock Layers & Fossils as Evidence
- **学什么 / What**：用岩层 (rock layers) 与化石 (fossils) 作为证据，说明地表景观随时间发生的变化。
- **掌握标准 / Mastery**：能依据岩层与化石推断过去的环境。
- **例子 / Example**：山上发现海洋生物化石，说明此处曾是海洋。

### 4.2 风化与侵蚀 / Weathering & Erosion
- **学什么 / What**：通过观察与测量说明风化 (weathering)、侵蚀 (erosion) 及其发生的速率 (rate)，认识水、冰、风、植物的作用。
- **掌握标准 / Mastery**：能设计实验比较不同条件下侵蚀的快慢。
- **例子 / Example**：水流冲刷沙堆，坡越陡冲走越快。

### 4.3 用地图描述地表特征 / Mapping Earth's Features
- **学什么 / What**：分析并解读地图 (maps) 上的数据，描述地震、火山、山脉等地球特征的分布模式 (patterns)。
- **掌握标准 / Mastery**：能从地图找出地质活动的分布规律。
- **例子 / Example**：发现火山多沿板块边界呈带状分布。

### 4.4 自然资源与能源燃料 / Natural Resources & Energy Fuels
- **学什么 / What**：认识能源与燃料 (energy and fuels) 来自自然资源 (natural resources)，它们的获取与使用会影响环境。
- **掌握标准 / Mastery**：能说明资源利用的利与环境代价。
- **例子 / Example**：燃烧煤发电会释放污染气体。

### 4.5 减少自然灾害影响 / Reducing Natural Hazard Impacts
- **学什么 / What**：生成并比较多种方案 (solutions)，以减少地震、洪水、海啸等自然灾害 (natural hazards) 对人类的影响。
- **掌握标准 / Mastery**：能提出并评价一项减灾措施。
- **例子 / Example**：在地震带建抗震建筑或设预警系统。

## 游戏化玩法建议 / Gamification Hooks
- **能量 / Energy**：「能量传送带」关卡——玩家把电能、光能、热能、声能的图标按转化链正确连接（电→光→热），点亮整条链路才能发电过关。
- **波 / Waves**：「波形调谐器」——拖动滑块调整振幅与波长去匹配目标波形，匹配成功后用波把小船推到岸边。
- **结构功能与信息处理 / Structure, Function & Information**：「感官接力赛」——光/声/气味刺激出现时，玩家点对应感官把信号送进大脑触发正确反应，反应慢就漏分。
- **地球的历史与系统 / Earth's History & Systems**：「岩层考古」——玩家逐层挖掘并按深浅排序化石，正确还原年代顺序解锁古环境图景；附「减灾建造」小关用预算选择抗震或防洪方案。
