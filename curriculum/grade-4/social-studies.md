# 四年级 · 社会研究 / Grade 4 · Social Studies

> 对齐标准：典型的美国四年级社会研究框架（美国地理 + 本州历史，按各州标准如 C3 Framework 调整）。本年级聚焦美国五大区域地理与「你所在的州」的历史、政府与经济。

## 本年级总目标 / Year Goals
四年级学生认识美国的五大地理区域、各州与首府及自然特征，能读懂并使用地图。
Fourth graders learn the five U.S. regions, states and capitals, physical features, and how to read and use maps.
他们以「你所在的州」为框架研究本州的地理、历史、政府与经济，了解原住民文化、探险殖民历史与政府运作。
Using "your state" as a framework, they study its geography, history, government, and economy, and explore Native American cultures, exploration and settlement, and how government works.

> 说明 / Note：本州 (your state) 部分采用通用框架表述，各州的具体地名、历史事件与政府结构不同，请按你所在州的标准填充具体内容。

## 1. 美国地理 / U.S. Geography

### 1.1 五大区域 / Five Regions
- **学什么 / What**：认识美国的五大地理区域 (regions)：东北部、东南部、中西部、西南部、西部。
- **掌握标准 / Mastery**：能说出各区域包含的主要州并描述其特点。
- **例子 / Example**：西部区域包括加利福尼亚、华盛顿等州。

### 1.2 各州与首府 / States & Capitals
- **学什么 / What**：在地图上定位 50 个州及其首府 (capitals)。
- **掌握标准 / Mastery**：能将主要州与其首府配对。
- **例子 / Example**：得克萨斯州的首府是奥斯汀。

### 1.3 自然特征 / Physical Features
- **学什么 / What**：识别山脉、河流、湖泊、平原、海岸等自然特征 (physical features)。
- **掌握标准 / Mastery**：能在地图上指出落基山脉、密西西比河等。
- **例子 / Example**：五大湖位于中西部与加拿大交界。

### 1.4 气候与地形 / Climate & Landforms
- **学什么 / What**：比较不同区域的气候 (climate) 与地形 (landforms) 差异。
- **掌握标准 / Mastery**：能说明气候与地形如何影响人们生活。
- **例子 / Example**：西南部干旱炎热，多沙漠地形。

### 1.5 读地图 / Reading Maps
- **学什么 / What**：使用比例尺、图例、指南针玫瑰、经纬度 (latitude/longitude) 等地图工具。
- **掌握标准 / Mastery**：能用地图工具确定位置与方向、估算距离。
- **例子 / Example**：用图例区分首府与普通城市。

## 2. 本州历史与地理 / State History & Geography（你所在的州 / Your State）

### 2.1 本州地理 / State Geography
- **学什么 / What**：研究你所在州的位置、边界、主要自然特征与区域划分。
- **掌握标准 / Mastery**：能描述本州的地形、河流与气候。
- **例子 / Example**：（按本州填充）说明本州主要河流及其作用。

### 2.2 本州历史 / State History
- **学什么 / What**：了解本州从原住民、探险殖民到建州 (statehood) 的关键历史阶段与人物。
- **掌握标准 / Mastery**：能按时间顺序排列本州重大历史事件。
- **例子 / Example**：（按本州填充）本州何时、如何加入联邦。

### 2.3 本州政府 / State Government
- **学什么 / What**：了解本州政府结构与州宪法 (state constitution)。
- **掌握标准 / Mastery**：能说出本州州长及立法机构的作用。
- **例子 / Example**：（按本州填充）本州州府所在城市。

### 2.4 本州经济 / State Economy
- **学什么 / What**：了解本州的主要自然资源、产业与经济活动。
- **掌握标准 / Mastery**：能说明本州经济的支柱产业。
- **例子 / Example**：（按本州填充）本州的农业或制造业特色。

## 3. 原住民 / Native American Peoples

### 3.1 各地区原住民文化 / Regional Indigenous Cultures
- **学什么 / What**：了解欧洲人到来前 (before European contact) 北美各地区原住民 (Native Americans) 的文化、住所、食物与社会组织。
- **掌握标准 / Mastery**：能比较至少两个地区原住民的生活方式差异。
- **例子 / Example**：平原原住民依赖野牛，东北林地原住民种植玉米。

### 3.2 与环境的关系 / Relationship with Environment
- **学什么 / What**：理解原住民如何利用并适应当地自然环境。
- **掌握标准 / Mastery**：能说明环境如何塑造其衣食住行。
- **例子 / Example**：西北沿海原住民以捕鱼为生。

## 4. 探险与殖民 / Exploration & Settlement

### 4.1 探险家 / Explorers
- **学什么 / What**：了解到达美洲的主要探险家 (explorers) 及其动机与影响。
- **掌握标准 / Mastery**：能把探险家与其国家、路线配对。
- **例子 / Example**：哥伦布代表西班牙横渡大西洋。

### 4.2 早期定居点 / Early Settlements
- **学什么 / What**：了解早期欧洲定居点 (settlements) 的建立与生活。
- **掌握标准 / Mastery**：能说明定居者面临的挑战。
- **例子 / Example**：早期定居者需应对粮食短缺与严冬。

### 4.3 殖民 / Colonization
- **学什么 / What**：理解殖民 (colonization) 对原住民与土地的影响。
- **掌握标准 / Mastery**：能描述殖民带来的文化与人口变化。
- **例子 / Example**：殖民扩张导致原住民被迫迁移。

## 5. 政府 / Government

### 5.1 政府层级 / Levels of Government
- **学什么 / What**：区分联邦 (federal)、州 (state)、地方 (local) 三级政府的职责。
- **掌握标准 / Mastery**：能举例说明各级政府负责的事务。
- **例子 / Example**：地方政府管理学校与垃圾收集。

### 5.2 三权分立入门 / Introduction to Three Branches
- **学什么 / What**：认识立法 (legislative)、行政 (executive)、司法 (judicial) 三权及其职能。
- **掌握标准 / Mastery**：能把三权与「制定/执行/解释法律」对应。
- **例子 / Example**：国会制定法律，总统执行法律。

### 5.3 州宪法 / State Constitution
- **学什么 / What**：了解州宪法 (state constitution) 的作用及与联邦宪法的关系。
- **掌握标准 / Mastery**：能说明宪法为何重要。
- **例子 / Example**：州宪法规定本州政府的组织方式。

### 5.4 权利与责任 / Rights & Responsibilities
- **学什么 / What**：了解公民的基本权利 (rights) 与责任 (responsibilities)。
- **掌握标准 / Mastery**：能区分权利与责任并各举一例。
- **例子 / Example**：投票既是权利也是公民责任。

## 6. 经济 / Economics

### 6.1 自然资源与产业 / Natural Resources & Industry
- **学什么 / What**：认识自然资源 (natural resources) 如何支撑产业 (industry) 与经济活动。
- **掌握标准 / Mastery**：能把资源与对应产业配对。
- **例子 / Example**：丰富森林支撑木材业。

### 6.2 经济区域 / Economic Regions
- **学什么 / What**：理解不同区域因资源不同而形成不同经济特色 (economic regions)。
- **掌握标准 / Mastery**：能说明区域经济差异的成因。
- **例子 / Example**：中西部以农业为主，称「粮仓」。

### 6.3 贸易 / Trade
- **学什么 / What**：理解区域间与国家间的贸易 (trade)、进出口如何满足需求。
- **掌握标准 / Mastery**：能说明为什么地区间要互相交换商品。
- **例子 / Example**：温暖地区把水果运往寒冷地区销售。

### 6.4 稀缺 / Scarcity
- **学什么 / What**：理解稀缺 (scarcity) 指资源有限而需求无限，需作出选择。
- **掌握标准 / Mastery**：能用稀缺解释为什么要做经济选择。
- **例子 / Example**：水资源有限的地区需节约用水。

### 6.5 供给与需求 / Supply & Demand
- **学什么 / What**：理解供给 (supply) 与需求 (demand) 如何影响价格。
- **掌握标准 / Mastery**：能说明供需变化对价格的影响。
- **例子 / Example**：某玩具供不应求，价格上涨。

## 游戏化玩法建议 / Gamification Hooks
- **美国地理 / U.S. Geography**：「五十州拼图赛」——玩家把州的形状拖到正确位置并放上首府旗子，限时拼对整个区域得星。
- **本州历史与地理 / State History & Geography**：「时光列车」——沿本州历史时间线驾驶列车，在每站回答关于该时期事件的问题才能继续前进。
- **原住民 / Native American Peoples**：「部落生活模拟」——根据所处地理区域（平原/林地/沿海）选择正确的食物、住所与工具维持部落生存。
- **探险与殖民 / Exploration & Settlement**：「航海探险家」——规划探险家的路线并管理补给，正确决策才能抵达新大陆。
- **政府 / Government**：「三权分配台」——把不同政务卡片投入立法/行政/司法的正确槽位，分错会触发「权力越界」警告。
- **经济 / Economics**：「市场摊主」——根据供需信号调整商品价格与进货量，平衡稀缺资源以最大化收益。
