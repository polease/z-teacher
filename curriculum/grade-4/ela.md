# 四年级 · 英语语言艺术 / Grade 4 · English Language Arts

> 对齐标准：Common Core State Standards for English Language Arts, Grade 4 (CCSS-ELA G4)。本年级强调引用文本细节作推断、跨文本整合信息、并写出有组织、有证据的多类型文章。

## 本年级总目标 / Year Goals
四年级学生能流利阅读多音节词，引用文本细节进行推断，归纳文学与信息文本的主题与主旨。
Fourth graders read multisyllabic words fluently, quote text details to make inferences, and determine themes and main ideas in literature and informational texts.
他们写出观点、说明、记叙三类成文文章，运用规范语法与精确词汇，并能在有准备的讨论中接续他人观点。
They write opinion, informative, and narrative pieces using correct grammar and precise vocabulary, and build on others' ideas in prepared discussions.

## 1. 基础阅读技能 / Foundational Skills

### 1.1 拼读多音节词 / Decode Multisyllabic Words
- **学什么 / What**：运用字母-语音与词素 (morphology) 知识拼读不熟悉的多音节词，识别常见词根与词缀 (roots and affixes)。
- **掌握标准 / Mastery**：能准确拼读课文中绝大多数多音节词。
- **例子 / Example**：把 "unbelievable" 拆成 un-believ-able 来读。

### 1.2 流利阅读 / Fluency
- **学什么 / What**：以恰当速度、准确度与表达力 (expression) 朗读年级文本，必要时自我纠正。
- **掌握标准 / Mastery**：朗读流畅、停顿合理，能支持理解。
- **例子 / Example**：朗读一段故事时按标点停顿并读出角色语气。

## 2. 文学类阅读 / Reading Literature

### 2.1 引用细节作推断 / Cite Details & Infer
- **学什么 / What**：明确引用文本内容来解释文本明说的内容，并据此作推断 (inference)。
- **掌握标准 / Mastery**：能指出文中具体句子支撑自己的推断。
- **例子 / Example**：从「他握紧拳头」推断角色生气。

### 2.2 归纳主题与概括 / Theme & Summary
- **学什么 / What**：从文本细节中归纳主题 (theme)，并概括 (summarize) 故事内容。
- **掌握标准 / Mastery**：能用自己的话概括而不夹带个人意见。
- **例子 / Example**：从故事归纳「坚持就会成功」的主题。

### 2.3 描述角色场景事件 / Describe Character, Setting, Event
- **学什么 / What**：依据文本细节（如角色的想法、言行）深入描述角色、场景与事件。
- **掌握标准 / Mastery**：能用文本证据支持对角色的描述。
- **例子 / Example**：用「她每天提前到校」说明角色勤奋。

### 2.4 理解词义与典故 / Word Meaning & Allusions
- **学什么 / What**：理解文本中词句含义，包括出自神话典故 (allusions to mythology) 的词语。
- **掌握标准 / Mastery**：能解释含典故词语的含义。
- **例子 / Example**：理解 "Herculean task" 指极其艰巨的任务。

### 2.5 诗歌戏剧散文的结构 / Structure of Poems, Drama, Prose
- **学什么 / What**：识别诗行 (verse)、韵律 (rhythm)、角色表 (cast of characters)、舞台说明 (stage directions) 等结构要素。
- **掌握标准 / Mastery**：能指出三种体裁的结构差异。
- **例子 / Example**：辨认剧本中的舞台说明「（轻声地）」。

### 2.6 比较叙述视角 / Compare Point of View
- **学什么 / What**：比较第一人称 (first-person) 与第三人称 (third-person) 叙述的不同。
- **掌握标准 / Mastery**：能判断叙述视角并说明影响。
- **例子 / Example**：用「我」叙述是第一人称。

### 2.7 连接文本与影音 / Text to Multimedia
- **学什么 / What**：把文本的文字描述与其影音、舞台或视觉呈现作连接对比。
- **掌握标准 / Mastery**：能指出版本之间的异同。
- **例子 / Example**：比较小说与其改编电影中某场景的差异。

### 2.8 比较文化故事 / Compare Cultural Stories
- **学什么 / What**：比较不同文化的故事、神话、传说在主题与情节模式 (patterns of events) 上的相似与不同（如善恶对立）。
- **掌握标准 / Mastery**：能找出跨文化故事的共同模式。
- **例子 / Example**：比较中外灰姑娘型故事。

## 3. 信息类阅读 / Reading Informational

### 3.1 细节与推断 / Details & Inference
- **学什么 / What**：引用信息文本细节作解释与推断。
- **掌握标准 / Mastery**：能用文中数据或事实支撑结论。
- **例子 / Example**：从降雨数据推断某地气候湿润。

### 3.2 主旨与概括 / Main Idea & Summary
- **学什么 / What**：确定主旨 (main idea) 及其支撑细节，并概括文本。
- **掌握标准 / Mastery**：能区分主旨与支撑细节。
- **例子 / Example**：一段讲蜜蜂的文本主旨是「蜜蜂帮助植物授粉」。

### 3.3 解释事件步骤概念 / Explain Events, Procedures, Concepts
- **学什么 / What**：依据文本具体解释历史事件、操作步骤或科学/技术概念，说明发生原因。
- **掌握标准 / Mastery**：能基于文本说明「为什么」与「怎么样」。
- **例子 / Example**：解释水循环各步骤如何相连。

### 3.4 学术与专业词汇 / Academic & Domain Vocabulary
- **学什么 / What**：理解某学科领域相关的学术词与专业词 (domain-specific words)。
- **掌握标准 / Mastery**：能根据上下文确定专业词含义。
- **例子 / Example**：在科学文本中理解 "evaporation"。

### 3.5 文本结构 / Text Structure
- **学什么 / What**：识别时间顺序 (chronology)、比较 (comparison)、因果 (cause/effect)、问题-解决 (problem/solution) 等结构。
- **掌握标准 / Mastery**：能指出整篇或某段所用结构。
- **例子 / Example**：识别「先…然后…最后」为时间顺序结构。

### 3.6 比较第一手与第二手记述 / Firsthand vs. Secondhand
- **学什么 / What**：比较同一事件或主题的第一手 (firsthand) 与第二手 (secondhand) 记述，关注其侧重与信息差异。
- **掌握标准 / Mastery**：能区分亲历者叙述与他人转述。
- **例子 / Example**：比较探险家日记与百科条目。

### 3.7 解读可视化信息 / Interpret Visuals
- **学什么 / What**：解读图表、图示、时间线 (timeline)、动画等可视化与量化信息，并说明其如何帮助理解。
- **掌握标准 / Mastery**：能把图表信息与正文联系起来。
- **例子 / Example**：用时间线说明事件发生顺序。

### 3.8 分析理由与证据 / Reasons & Evidence
- **学什么 / What**：分析作者用哪些理由 (reasons) 与证据 (evidence) 支持论点。
- **掌握标准 / Mastery**：能把具体证据与对应观点配对。
- **例子 / Example**：找出作者支持「应多运动」的两条证据。

### 3.9 整合两篇文本 / Integrate Two Texts
- **学什么 / What**：整合同一主题两篇文本的信息，以便有条理地写作或表达。
- **掌握标准 / Mastery**：能综合两文本观点形成自己的论述。
- **例子 / Example**：合并两篇关于回收的文章写一段总结。

## 4. 写作 / Writing

### 4.1 观点类写作 / Opinion Writing
- **学什么 / What**：写出有立场的文章，把支持理由分组 (group reasons)，用连接词 (linking words) 衔接，并用事实与细节作证据。
- **掌握标准 / Mastery**：含明确观点、分组理由、相关证据与结论。
- **例子 / Example**：写「为什么学校应延长课间」并给三条理由。

### 4.2 说明类写作 / Informative Writing
- **学什么 / What**：清晰说明主题，用小标题 (headings)、插图 (illustrations)、精确用词与专业词汇组织信息。
- **掌握标准 / Mastery**：信息分组合理，有引入、展开与总结。
- **例子 / Example**：写一篇介绍火山的说明文并配图。

### 4.3 记叙类写作 / Narrative Writing
- **学什么 / What**：写真实或想象的故事，含铺垫 (orientation)、对话 (dialogue)、节奏 (pacing)、过渡词、具体词、五感描写与结尾。
- **掌握标准 / Mastery**：情节连贯，有人物对话与有力结尾。
- **例子 / Example**：写一次露营经历，加入对话和感官细节。

### 4.4 计划修改编辑 / Plan, Revise, Edit
- **学什么 / What**：在指导下计划、修改 (revise) 与编辑 (edit) 文章以增强表达。
- **掌握标准 / Mastery**：能根据反馈改进草稿。
- **例子 / Example**：把模糊句改写得更具体。

### 4.5 用技术工具与打字 / Technology & Keyboarding
- **学什么 / What**：用技术工具写作与发表，能一次打满至少一页 (one page) 文字。
- **掌握标准 / Mastery**：能熟练用键盘录入并与他人协作。
- **例子 / Example**：用文档软件打出一页作文。

### 4.6 开展研究 / Conduct Research
- **学什么 / What**：完成短期研究项目，回忆经验与从来源 (sources) 收集信息、记笔记 (take notes)、分类。
- **掌握标准 / Mastery**：能从多个来源取证并归类记录。
- **例子 / Example**：调查一种动物并做信息卡。

### 4.7 从文本中找证据 / Draw Evidence from Texts
- **学什么 / What**：从文学或信息文本中提取证据以支持分析与反思。
- **掌握标准 / Mastery**：能引用文本支持自己的写作。
- **例子 / Example**：用原文句子支持对角色的评价。

## 5. 口语与倾听 / Speaking & Listening

### 5.1 参与讨论 / Engage in Discussions
- **学什么 / What**：有准备地参加讨论，遵守分工与规则，接续他人观点 (build on others' ideas) 并反思。
- **掌握标准 / Mastery**：能提出与回应问题，推动讨论深入。
- **例子 / Example**：小组讨论中先复述同学观点再补充。

### 5.2 转述媒体信息 / Paraphrase Media
- **学什么 / What**：转述 (paraphrase) 以多种媒体形式呈现的文本与信息。
- **掌握标准 / Mastery**：能用自己的话准确复述要点。
- **例子 / Example**：看完短片后口头总结主要内容。

### 5.3 辨别说话者的理由与证据 / Speaker's Reasons & Evidence
- **学什么 / What**：指出说话者用哪些理由与证据支持观点。
- **掌握标准 / Mastery**：能听出并说明发言中的论据。
- **例子 / Example**：听同学发言后指出其两条理由。

### 5.4 带细节作汇报 / Report with Details
- **学什么 / What**：就主题或文本作汇报，叙述经历，用恰当事实与细节，必要时加入影音 (audio/visual)。
- **掌握标准 / Mastery**：表达清晰、有条理、语速适中。
- **例子 / Example**：用幻灯片汇报一次科学小实验。

### 5.5 正式与非正式英语 / Formal vs. Informal English
- **学什么 / What**：区分应使用正式英语 (formal English) 与可使用非正式英语 (informal English) 的场合。
- **掌握标准 / Mastery**：能根据场合调整用语。
- **例子 / Example**：课堂汇报用正式语，课间聊天可随意。

## 6. 语言规范 / Language

### 6.1 关系代词与关系副词 / Relative Pronouns & Adverbs
- **学什么 / What**：正确使用 who, whose, whom, which, that 及 where, when, why。
- **掌握标准 / Mastery**：能在句中正确选用。
- **例子 / Example**：The book that I read was fun.

### 6.2 进行时态与情态助动词 / Progressive Tenses & Modals
- **学什么 / What**：使用进行时 (was walking) 与情态助动词 (can, may, must) 表达意图与条件。
- **掌握标准 / Mastery**：能正确表达正在进行与可能性。
- **例子 / Example**：I was reading. / You must wait.

### 6.3 形容词排序与介词短语 / Adjective Order & Prepositional Phrases
- **学什么 / What**：按常规顺序排列形容词，正确使用介词短语 (prepositional phrases)。
- **掌握标准 / Mastery**：能写出符合习惯的短语。
- **例子 / Example**：a small red ball；in the morning。

### 6.4 完整句 / Complete Sentences
- **学什么 / What**：辨别并改正句子片段 (fragments) 与流水句 (run-ons)。
- **掌握标准 / Mastery**：能产出完整且不冗长的句子。
- **例子 / Example**：把 "Running fast." 改为完整句。

### 6.5 易混词 / Frequently Confused Words
- **学什么 / What**：正确使用 to/too/two、there/their/they're 等易混词。
- **掌握标准 / Mastery**：在写作中用对这些词。
- **例子 / Example**：They're going to their house there.

### 6.6 大写与标点 / Capitalization & Punctuation
- **学什么 / What**：正确大写；用逗号引号标记对话与直接引语 (quotation marks)；并列复合句中并列连词前用逗号。
- **掌握标准 / Mastery**：对话与并列句标点正确。
- **例子 / Example**："Let's go," she said. / It rained, so we stayed in.

### 6.7 拼写与精确选词 / Spelling & Word Choice
- **学什么 / What**：拼写年级常用词，必要时查参考资料；为表达精确而选词。
- **掌握标准 / Mastery**：拼写准确，用词贴切。
- **例子 / Example**：用 "sprint" 代替 "run fast"。

### 6.8 习语谚语与同反义词 / Idioms, Synonyms & Antonyms
- **学什么 / What**：理解习语 (idioms)、谚语 (proverbs)、格言 (adages)，掌握同义词 (synonyms) 与反义词 (antonyms)。
- **掌握标准 / Mastery**：能解释常见习语并配对同反义词。
- **例子 / Example**：理解 "break the ice"；happy 的反义词是 sad。

### 6.9 希腊拉丁词根词缀 / Greek & Latin Roots
- **学什么 / What**：用常见希腊拉丁词根与词缀 (roots and affixes) 推断词义。
- **掌握标准 / Mastery**：能借助词根猜出陌生词含义。
- **例子 / Example**：tele- 表「远」，telephone 即远距通话。

## 游戏化玩法建议 / Gamification Hooks
- **文学类阅读 / Reading Literature**：「证据侦探」关卡——给出一句推断，玩家在文段中高亮能支持它的句子，命中正确证据解锁线索。
- **信息类阅读 / Reading Informational**：「结构分类器」——把段落卡片拖入「时间顺序/因果/比较/问题解决」四个盒子，正确归类点亮通道。
- **写作 / Writing**：「叙事拼图」——把铺垫、对话、高潮、结尾的句块按节奏排序组成完整故事，顺序对才能发布。
- **口语与倾听 / Speaking & Listening**：「正式语切换器」——同一句话给出正式与非正式两版，玩家根据场景图标（课堂/操场）选对版本得分。
- **语言规范 / Language**：「词根熔炉」——拖动词根与词缀拼成真实单词并显示词义，拼出不存在的词会熄灭炉火。
