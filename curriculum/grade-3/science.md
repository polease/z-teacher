# 三年级 · 科学 / Grade 3 · Science

> 对齐标准：新一代科学标准（Next Generation Science Standards, NGSS, Grade 3）。本年级围绕力与运动、生命周期与遗传、群体与适应、天气与气候四大主题。

## 本年级总目标 / Year Goals
本学年学生将通过观察与实验，理解力如何影响运动，包括看不见的电力与磁力。
Students will investigate how forces affect motion, including invisible electric and magnetic forces.
学生将研究生物的生命周期、性状的遗传与变异，以及生物如何适应环境。
Students will study life cycles, inheritance and variation of traits, and how organisms adapt to environments.
学生还将用数据描述天气与气候，并设计减少天气灾害影响的方案。
Students will use data to describe weather and climate and design solutions to reduce weather hazards.

## 1. 力与相互作用 / Forces & Interactions (3-PS2)

### 1.1 平衡力与不平衡力 / Balanced & Unbalanced Forces
- **学什么 / What**：物体受到的力是否平衡（balanced/unbalanced）决定它的运动是否改变。
- **掌握标准 / Mastery**：能通过实验证据说明不平衡力会改变物体的运动。
- **例子 / Example**：两人拔河力相等时绳子不动（平衡）；一边更用力绳子就移动（不平衡）。

### 1.2 用运动规律预测 / Predicting Motion with Patterns
- **学什么 / What**：观察物体运动的规律（patterns of motion），用它预测未来的运动。
- **掌握标准 / Mastery**：能根据观察到的规律预测下一步运动。
- **例子 / Example**：荡秋千有规律地来回，可预测下一次到达的位置。

### 1.3 电力（不接触也作用） / Electric Forces at a Distance
- **学什么 / What**：电力（electric force）即使物体不接触也能作用。
- **掌握标准 / Mastery**：能举证静电吸引/排斥不需接触。
- **例子 / Example**：摩擦过的气球能隔空吸起小纸片或头发。

### 1.4 磁力（不接触也作用） / Magnetic Forces at a Distance
- **学什么 / What**：磁力（magnetic force）也能在不接触时产生吸引或排斥。
- **掌握标准 / Mastery**：能说明磁极的吸引与排斥并随距离变化。
- **例子 / Example**：两块磁铁同极相斥、异极相吸，隔着纸也能感受到。

### 1.5 用磁铁设计解决方案 / Design with Magnets
- **学什么 / What**：定义一个用磁性相互作用解决的问题（design a solution）。
- **掌握标准 / Mastery**：能设计并测试一个利用磁力的装置。
- **例子 / Example**：设计一个不用手就能分开两件物品的磁性闩锁。

## 2. 生命周期与遗传 / Life Cycles & Inheritance (3-LS1, 3-LS3)

### 2.1 多样的生命周期 / Diverse Life Cycles
- **学什么 / What**：生物有独特而多样的生命周期（life cycles），包括出生、生长、繁殖、死亡（birth, growth, reproduction, death）。
- **掌握标准 / Mastery**：能描述并比较不同生物的生命周期。
- **例子 / Example**：蝴蝶经历卵→幼虫→蛹→成虫；青蛙经历卵→蝌蚪→成蛙。

### 2.2 性状遗传自亲代 / Inherited Traits
- **学什么 / What**：许多性状（traits）由亲代遗传（inherited）给后代。
- **掌握标准 / Mastery**：能识别亲代与后代相似的性状。
- **例子 / Example**：小狗的毛色、耳形常与父母相似。

### 2.3 环境影响性状 / Environment Affects Traits
- **学什么 / What**：性状也会受到环境（environment）的影响。
- **掌握标准 / Mastery**：能举例说明环境如何改变生物特征。
- **例子 / Example**：缺水的植物长得矮小；多锻炼使肌肉更强壮。

### 2.4 同种内的变异 / Variation Within a Species
- **学什么 / What**：同一物种内的个体存在差异（variation）。
- **掌握标准 / Mastery**：能观察并描述同种生物间的不同。
- **例子 / Example**：同一窝小猫毛色、体型各不相同。

## 3. 群体行为与适应 / Social Behavior & Adaptation (3-LS2, 3-LS4)

### 3.1 成群有助生存 / Groups Help Survival
- **学什么 / What**：成群生活（forming groups）能帮助动物生存。
- **掌握标准 / Mastery**：能解释群体在觅食、防御中的好处。
- **例子 / Example**：狼群合作捕猎；鱼群迷惑捕食者。

### 3.2 化石作为古环境证据 / Fossils as Evidence
- **学什么 / What**：化石（fossils）提供古代生物及其环境的证据。
- **掌握标准 / Mastery**：能用化石推断过去的环境。
- **例子 / Example**：沙漠里发现海洋生物化石，说明那里曾是海洋。

### 3.3 变异带来生存优势 / Advantageous Variation
- **学什么 / What**：某些变异（variations）让个体更容易生存、找配偶、繁殖（survive, find mates, reproduce）。
- **掌握标准 / Mastery**：能说明某性状如何提供优势。
- **例子 / Example**：颜色与环境相近的昆虫不易被天敌发现。

### 3.4 栖息地支持不同生物 / Habitats Support Different Organisms
- **学什么 / What**：不同栖息地（habitats）支持不同种类的生物。
- **掌握标准 / Mastery**：能把生物与其适宜栖息地匹配。
- **例子 / Example**：仙人掌适应沙漠；睡莲适应池塘。

### 3.5 环境变化的影响 / Effects of Environmental Change
- **学什么 / What**：环境变化（environmental change）会使生物迁移、适应或死亡。
- **掌握标准 / Mastery**：能预测环境变化对生物的影响。
- **例子 / Example**：池塘干涸后，鱼无法生存而青蛙可迁往别处。

## 4. 天气与气候 / Weather & Climate (3-ESS2, 3-ESS3)

### 4.1 季节天气数据 / Seasonal Weather Data
- **学什么 / What**：用表格和图表（tables and graphs）表示某地某季节的典型天气（typical weather）。
- **掌握标准 / Mastery**：能读懂并制作天气数据图表。
- **例子 / Example**：记录一周气温与降雨，画成条形图。

### 4.2 不同地区的气候 / Climates in Different Regions
- **学什么 / What**：气候（climate）是某地区长期的天气模式，不同地区气候不同。
- **掌握标准 / Mastery**：能区分天气（短期）与气候（长期）。
- **例子 / Example**：热带常年炎热多雨；极地终年寒冷。

### 4.3 设计减灾方案 / Design Solutions to Reduce Hazards
- **学什么 / What**：设计方案以减少天气相关灾害（weather-related hazards）的影响。
- **掌握标准 / Mastery**：能提出并评估一个减灾设计。
- **例子 / Example**：用避雷针防雷击；用防风带减少暴风影响。

## 游戏化玩法建议 / Gamification Hooks
- **力与相互作用 / Forces**：「磁力迷宫」用看不见的磁力隔空推动小球绕过障碍到终点。
- **生命周期 / Life Cycles**：「变态大冒险」按正确顺序拼出蝴蝶/青蛙生命周期阶段过关。
- **遗传与变异 / Inheritance**：「小狗工坊」根据父母性状搭配后代，匹配遗传规律得分。
- **群体与适应 / Adaptation**：「伪装大师」给昆虫选与环境最匹配的颜色，躲过天敌存活。
- **化石 / Fossils**：「时光挖掘」根据化石线索还原古代环境的判断关卡。
- **天气气候 / Weather**：「气象站」收集数据画图表，再设计减灾装置抵御来袭风暴。
