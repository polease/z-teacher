# 三年级 · 英语语言艺术 / Grade 3 · English Language Arts

> 对齐标准：美国共同核心州立标准（Common Core State Standards, CCSS - ELA, Grade 3）。本年级强调从文本中引用证据、深入理解人物与主旨，并写出有结构的文章。

## 本年级总目标 / Year Goals
本学年学生将能流利朗读并理解年级水平文本，回答问题时明确引用文本依据。
Students will read grade-level texts fluently and refer explicitly to the text when answering questions.
学生将复述故事提炼寓意、分析人物，并写出观点类、说明类与记叙类文章。
Students will recount stories to find the message, analyze characters, and write opinion, informative, and narrative pieces.
学生还将掌握词性、句型与拼写规律，并参与有规则的课堂讨论。
Students will master parts of speech, sentence types, and spelling patterns, and join collaborative discussions.

## 1. 基础阅读技能 / Foundational Skills

### 1.1 拼读前后缀 / Prefixes & Suffixes
- **学什么 / What**：识别常见前缀（prefixes）和后缀（suffixes）及其含义。
- **掌握标准 / Mastery**：能用词缀推断词义并正确拼读。
- **例子 / Example**：un- + happy = unhappy；care + -less = careless。

### 1.2 拉丁后缀 / Latin Suffixes
- **学什么 / What**：识别常见的拉丁后缀（Latin suffixes）。
- **掌握标准 / Mastery**：能拼读含 -tion、-able、-ible 等的词。
- **例子 / Example**：act → action；comfort → comfortable。

### 1.3 音节模式与多音节词 / Syllable Patterns & Multisyllabic Words
- **学什么 / What**：用音节切分模式（syllable patterns）拼读多音节词。
- **掌握标准 / Mastery**：能正确切分并朗读较长单词。
- **例子 / Example**：fan-tas-tic；but-ter-fly。

### 1.4 不规则词 / Irregular Words
- **学什么 / What**：准确认读年级水平的不规则拼写词（irregularly spelled words）。
- **掌握标准 / Mastery**：能即时认读高频不规则词。
- **例子 / Example**：though、enough、through。

### 1.5 流利阅读 / Fluency
- **学什么 / What**：以合适的准确度、速度和表达（accuracy, rate, expression）朗读。
- **掌握标准 / Mastery**：能用上下文自我修正读音。
- **例子 / Example**：朗读时遇到错读能停下并改正。

## 2. 文学类阅读 / Reading Literature

### 2.1 引用文本回答问题 / Ask & Answer with Text Evidence
- **学什么 / What**：回答问题时明确引用文本（refer explicitly to the text）作为依据。
- **掌握标准 / Mastery**：能指出支持答案的具体句子。
- **例子 / Example**：「她为什么害怕？」——「因为第 3 段说门突然打开了。」

### 2.2 复述与中心寓意 / Recount & Central Message
- **学什么 / What**：复述寓言、民间故事、神话（fables, folktales, myths）并提炼中心寓意（central message/lesson）。
- **掌握标准 / Mastery**：能说明寓意是如何通过情节体现的。
- **例子 / Example**：龟兔赛跑的寓意是「坚持比天赋更重要」。

### 2.3 描述角色 / Describe Characters
- **学什么 / What**：描述角色的性格、动机、感受（traits, motivations, feelings）及其对情节的影响。
- **掌握标准 / Mastery**：能说明角色行为如何推动事件发展。
- **例子 / Example**：因为主角贪心，才导致后面失去一切。

### 2.4 字面义与非字面义 / Literal & Nonliteral Language
- **学什么 / What**：区分词句的字面义（literal）与非字面义（nonliteral）。
- **掌握标准 / Mastery**：能解释比喻、习语的真实含义。
- **例子 / Example**：「像猫一样安静」表示非常安静。

### 2.5 故事结构衔接 / Story Structure
- **学什么 / What**：理解章节、场景、诗节（chapters, scenes, stanzas）如何前后衔接。
- **掌握标准 / Mastery**：能说明某一部分如何承接上文。
- **例子 / Example**：第二章解释了第一章谜题的原因。

### 2.6 叙述者与视角 / Narrator & Point of View
- **学什么 / What**：区分自己、叙述者（narrator）与角色（characters）的观点。
- **掌握标准 / Mastery**：能识别故事是谁在讲述。
- **例子 / Example**：用「我」讲的是第一人称视角。

### 2.7 插图的作用 / Role of Illustrations
- **学什么 / What**：说明插图（illustrations）如何强化文本的情绪、氛围或情节。
- **掌握标准 / Mastery**：能指出图画补充了哪些信息。
- **例子 / Example**：暗色调插图烘托紧张气氛。

### 2.8 比较同一作者作品 / Compare Works by Same Author
- **学什么 / What**：比较同一作者同系列书的主题、场景、情节（theme, setting, plot）。
- **掌握标准 / Mastery**：能找出共同点与不同点。
- **例子 / Example**：两本书的主角都勇敢，但冒险地点不同。

## 3. 信息类阅读 / Reading Informational

### 3.1 引用证据 / Cite Evidence
- **学什么 / What**：明确引用文本回答关于信息类文本的问题。
- **掌握标准 / Mastery**：能定位支持答案的句子。
- **例子 / Example**：「蝙蝠如何导航？」——文中说「靠回声定位」。

### 3.2 主旨与关键细节 / Main Idea & Key Details
- **学什么 / What**：确定主旨（main idea）并用关键细节支持。
- **掌握标准 / Mastery**：能概括段落要点。
- **例子 / Example**：本文主旨是「蜜蜂帮助植物授粉」。

### 3.3 关系（因果/顺序/时间） / Relationships
- **学什么 / What**：描述事件、概念、步骤间的因果、顺序、时间（cause/effect, sequence, time）关系。
- **掌握标准 / Mastery**：能用连接词说明逻辑关系。
- **例子 / Example**：先加热水，然后放入种子，最后观察。

### 3.4 学术词汇 / Academic Vocabulary
- **学什么 / What**：理解领域相关的学术与专业词汇（domain-specific words）。
- **掌握标准 / Mastery**：能借助上下文确定专业词含义。
- **例子 / Example**：在天气文中理解「降水 precipitation」。

### 3.5 文本特征与检索工具 / Text Features & Search Tools
- **学什么 / What**：使用关键词、侧栏、超链接（keywords, sidebars, hyperlinks）等定位信息。
- **掌握标准 / Mastery**：能快速找到所需信息。
- **例子 / Example**：用目录和加粗关键词查找「火山」一节。

### 3.6 区分观点 / Distinguish Point of View
- **学什么 / What**：区分自己的观点与作者的观点（own vs. author's point of view）。
- **掌握标准 / Mastery**：能说明哪些是作者立场、哪些是自己想法。
- **例子 / Example**：作者认为该保护森林，我也同意但理由不同。

### 3.7 插图与文字配合 / Illustrations & Words
- **学什么 / What**：说明图、地图、照片（maps, photos）如何帮助理解文本。
- **掌握标准 / Mastery**：能结合图文回答问题。
- **例子 / Example**：地图显示了文中提到的迁徙路线。

### 3.8 句段逻辑联系 / Logical Connections
- **学什么 / What**：理解句子和段落之间的逻辑连接（比较、因果、先后）。
- **掌握标准 / Mastery**：能识别连接词标示的关系。
- **例子 / Example**：「然而 however」表示转折对比。

### 3.9 比较两篇同主题文本 / Compare Two Texts
- **学什么 / What**：比较同一主题两篇文本的重点与信息。
- **掌握标准 / Mastery**：能列出共同点与差异。
- **例子 / Example**：两篇关于熊猫的文章，一篇讲食物，一篇讲栖息地。

## 4. 写作 / Writing

### 4.1 观点类写作 / Opinion Writing
- **学什么 / What**：写出有明确观点、组织结构、理由（reasons）和连接词（linking words）的文章。
- **掌握标准 / Mastery**：能用「因为/例如/还有」连接理由并有结尾。
- **例子 / Example**：「我认为狗是最好的宠物，因为它们忠诚……」。

### 4.2 说明类写作 / Informative Writing
- **学什么 / What**：用事实、定义、插图、分组（facts, definitions, grouping）说明主题。
- **掌握标准 / Mastery**：能分段并提供具体信息与结尾。
- **例子 / Example**：介绍「企鹅」的栖息地、食物、外形。

### 4.3 记叙类写作 / Narrative Writing
- **学什么 / What**：运用写作技巧、对话（dialogue）、描写、时间词（temporal words）讲述事件。
- **掌握标准 / Mastery**：能有清晰的开头、经过、结尾。
- **例子 / Example**：用「首先、接着、最后」叙述一次露营。

### 4.4 计划、修改与编辑 / Plan, Revise, Edit
- **学什么 / What**：在他人帮助下计划、修改、编辑（plan, revise, edit）习作。
- **掌握标准 / Mastery**：能根据反馈改进作文。
- **例子 / Example**：根据同伴建议增加细节和改正拼写。

### 4.5 用技术工具发布 / Publish with Technology
- **学什么 / What**：用数字工具（technology）打字并发布作品，与他人协作。
- **掌握标准 / Mastery**：能独立打出一段文字并排版。
- **例子 / Example**：在文档中打出并配图发布短文。

### 4.6 研究项目 / Research Projects
- **学什么 / What**：开展短期研究项目（research projects），围绕主题建构知识。
- **掌握标准 / Mastery**：能从多个来源收集信息。
- **例子 / Example**：调查「太阳系」并做小报告。

### 4.7 收集与归类信息 / Gather & Sort Information
- **学什么 / What**：从印刷与数字来源收集信息并归类（gather and sort）。
- **掌握标准 / Mastery**：能把笔记按类别整理。
- **例子 / Example**：把动物资料按「食物/天敌/栖息地」分类。

## 5. 口语与倾听 / Speaking & Listening

### 5.1 讨论规则与接续 / Discussion Rules & Building On
- **学什么 / What**：遵守讨论规则，倾听并接续他人发言（build on others' ideas）。
- **掌握标准 / Mastery**：能轮流发言并补充别人的想法。
- **例子 / Example**：「我同意小明的看法，还想补充……」。

### 5.2 提炼主旨细节 / Determine Main Ideas
- **学什么 / What**：从口头朗读或多媒体中提炼主旨与细节（main ideas and details）。
- **掌握标准 / Mastery**：能复述听到的关键信息。
- **例子 / Example**：听完讲述后说出文章讲了什么。

### 5.3 提问澄清 / Ask Clarifying Questions
- **学什么 / What**：提出问题以加深理解或澄清（clarify）。
- **掌握标准 / Mastery**：能提出相关而具体的问题。
- **例子 / Example**：「你说的那个词是什么意思？」。

### 5.4 主题汇报 / Report on a Topic
- **学什么 / What**：就主题或文本做汇报（report），叙述有条理、说话清楚。
- **掌握标准 / Mastery**：能以合理速度清晰表达。
- **例子 / Example**：做 1 分钟「我最喜欢的书」分享。

## 6. 语言规范 / Language

### 6.1 词性功能 / Parts of Speech
- **学什么 / What**：理解名词、代词、动词、形容词、副词（nouns, pronouns, verbs, adjectives, adverbs）的功能。
- **掌握标准 / Mastery**：能识别并正确使用各词性。
- **例子 / Example**：副词「quickly」修饰动词「ran」。

### 6.2 规则与不规则复数 / Regular & Irregular Plurals
- **学什么 / What**：构成规则与不规则名词复数（plural nouns）。
- **掌握标准 / Mastery**：能正确变 -s/-es 及不规则形式。
- **例子 / Example**：cat→cats；child→children；foot→feet。

### 6.3 抽象名词 / Abstract Nouns
- **学什么 / What**：识别与使用抽象名词（abstract nouns）。
- **掌握标准 / Mastery**：能在句中正确使用。
- **例子 / Example**：friendship、freedom、happiness。

### 6.4 规则与不规则动词 / Regular & Irregular Verbs
- **学什么 / What**：构成与使用规则及不规则动词（verbs）。
- **掌握标准 / Mastery**：能正确变过去式。
- **例子 / Example**：walk→walked；go→went；run→ran。

### 6.5 动词时态 / Verb Tenses
- **学什么 / What**：使用简单过去、现在、将来时（past, present, future tenses）。
- **掌握标准 / Mastery**：能根据时间正确选择时态。
- **例子 / Example**：I walked / I walk / I will walk。

### 6.6 主谓与代词一致 / Subject-Verb & Pronoun Agreement
- **学什么 / What**：保证主谓一致（subject-verb agreement）和代词一致（pronoun-antecedent agreement）。
- **掌握标准 / Mastery**：能纠正不一致的句子。
- **例子 / Example**：She runs（不是 She run）。

### 6.7 比较级与最高级 / Comparatives & Superlatives
- **学什么 / What**：使用形容词与副词的比较级、最高级（comparative, superlative）。
- **掌握标准 / Mastery**：能正确选择 -er/-est 或 more/most。
- **例子 / Example**：tall→taller→tallest；more careful。

### 6.8 连词 / Conjunctions
- **学什么 / What**：使用并列连词（coordinating）与从属连词（subordinating）。
- **掌握标准 / Mastery**：能用连词连接想法。
- **例子 / Example**：and, but, or；because, when, although。

### 6.9 句子类型 / Sentence Types
- **学什么 / What**：写出简单句、并列句、复合句（simple, compound, complex）。
- **掌握标准 / Mastery**：能正确组合分句。
- **例子 / Example**：复合句「When it rained, we stayed inside.」。

### 6.10 大写与标点 / Capitalization & Punctuation
- **学什么 / What**：标题大写（titles），地址与对话中用逗号（commas in addresses and dialogue），所有格（possessives）。
- **掌握标准 / Mastery**：能正确加逗号、撇号和大写。
- **例子 / Example**："Hello," she said.；the dog's bone。

### 6.11 拼写 / Spelling
- **学什么 / What**：拼写高频词（high-frequency words）、加后缀的拼写规律。
- **掌握标准 / Mastery**：能运用规律拼写新词。
- **例子 / Example**：hop→hopping（双写）；happy→happier（y变i）。

### 6.12 选词与词义关系 / Word Choice & Word Relationships
- **学什么 / What**：为表达效果选词（choose words for effect），理解字面/非字面义和词义关系（synonyms, real-life connections）。
- **掌握标准 / Mastery**：能区分近义词的细微差别。
- **例子 / Example**：「knew」与「believed」语气不同；happy 与 ecstatic 程度不同。

## 游戏化玩法建议 / Gamification Hooks
- **基础阅读 / Foundational**：「音节切割师」把多音节词切成正确音节块得分，限时连击。
- **文学阅读 / Literature**：「证据侦探」高亮文中支持答案的句子，找对越多积分越高。
- **信息阅读 / Informational**：「文本寻宝」用目录、侧栏、关键词在限定时间内找到答案。
- **写作 / Writing**：「故事拼装」用时间词卡片排出正确顺序，再补充对话与描写解锁结局。
- **口语倾听 / S&L**：「接龙圆桌」，每人必须先复述上一位再补充，断链扣分。
- **语言规范 / Language**：「词性分拣」把单词拖进对应词性篮，「时态变形」把动词变成指定时态闯关。
