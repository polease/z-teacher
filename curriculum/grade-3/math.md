# 三年级 · 数学 / Grade 3 · Mathematics

> 对齐标准：Common Core State Standards for Mathematics, Grade 3 (CCSS-M G3)。三年级数学以乘除法的意义、分数概念和面积/周长为核心 / Grade 3 math centers on the meaning of multiplication and division, fraction concepts, and area & perimeter.

## 本年级总目标 / Year Goals
理解乘法与除法的含义并能熟练计算一位数乘除；把分数理解为数轴上的数与整体的等分；掌握面积与周长并能解决两步应用题。
Students understand the meaning of multiplication and division and fluently compute within 100; they understand fractions as numbers on a number line and as equal parts of a whole; and they master area and perimeter while solving two-step word problems.

## 1. 运算与代数思维 / Operations & Algebraic Thinking

### 1.1 理解乘法（等组）/ Interpret Multiplication as Equal Groups
- **学什么 / What**：把 a×b 理解为 a 组、每组 b 个物体的总数（等组 equal groups, arrays 阵列）。
- **掌握标准 / Mastery**：看到 5×7 能说"5 组每组 7 个"并画出阵列。
- **例子 / Example**：5×7 = 5 行 7 列的点阵 = 35。

### 1.2 理解除法（等分与包含）/ Interpret Division
- **学什么 / What**：除法有两种含义——等分（partitive，56÷8 求每组几个）与包含（quotative/measurement，56÷8 求能分成几组）。
- **掌握标准 / Mastery**：对同一算式能讲出两种情境。
- **例子 / Example**：56÷8：56 个橘子平均分 8 盘，每盘 7 个；或 56 个橘子每盘 8 个，可装 7 盘。

### 1.3 乘除应用题（100 以内）/ Word Problems within 100
- **学什么 / What**：用乘除解决等组、阵列、测量量（measurement quantities）情境，含未知数（用符号表示 unknown）。
- **掌握标准 / Mastery**：能把文字题写成带未知数的乘除等式并求解。
- **例子 / Example**："3 排座位，每排 6 个，共几个？" 3×6=□。

### 1.4 求乘除等式中的未知数 / Find the Unknown in Equations
- **学什么 / What**：确定使乘除等式成立的未知整数（unknown whole number），未知数可在任意位置。
- **掌握标准 / Mastery**：能解 8×?=48、5=□÷3、6×6=? 等。
- **例子 / Example**：8 × ? = 48，答 6。

### 1.5 乘法的性质 / Properties of Multiplication
- **学什么 / What**：交换律（commutative，6×4=4×6）、结合律（associative，3×5×2 任意先乘）、分配律（distributive，8×7=8×(5+2)）。
- **掌握标准 / Mastery**：能用性质把难算的题拆成易算的。
- **例子 / Example**：8×7 = 8×5 + 8×2 = 40+16 = 56。

### 1.6 乘除互逆 / Division as Unknown-Factor
- **学什么 / What**：把除法理解为求未知因数（unknown-factor problem），32÷8 即 8×?=32。
- **掌握标准 / Mastery**：能用已知乘法事实推出除法结果。
- **例子 / Example**：32÷8 = 4，因为 8×4=32。

### 1.7 乘除熟练（100 以内）/ Fluency within 100
- **学什么 / What**：用策略（性质、互逆关系）流利乘除；**年底凭记忆掌握所有一位数相乘 / know from memory all products of two one-digit numbers**。
- **掌握标准 / Mastery**：3 秒内说出任意一位数乘法事实。
- **例子 / Example**：7×8=56 脱口而出。

### 1.8 两步混合运算应用题 / Two-Step Word Problems
- **学什么 / What**：用四则运算解两步问题；用字母表示未知量列方程；用心算与估算（rounding/estimation）判断答案合理性。
- **掌握标准 / Mastery**：能列方程、求解并解释答案是否合理。
- **例子 / Example**："买 3 件 4 元的玩具，付 20 元，找零？" 20−3×4=8。

### 1.9 算术规律 / Arithmetic Patterns
- **学什么 / What**：识别加法表/乘法表中的规律（patterns），并用性质解释。
- **掌握标准 / Mastery**：能说出"偶数乘任意数得偶数"等规律及原因。
- **例子 / Example**：4 的倍数都是偶数，因为 4=2×2。

## 2. 十进制数与运算 / Number & Operations in Base Ten

### 2.1 四舍五入 / Rounding
- **学什么 / What**：用位值理解四舍五入到最近的十位与百位（nearest 10 / 100）。
- **掌握标准 / Mastery**：能正确处理"5进位"边界。
- **例子 / Example**：147→十位 150，→百位 100。

### 2.2 千以内加减熟练 / Add & Subtract within 1000
- **学什么 / What**：基于位值、运算性质和加减互逆关系流利加减（strategies and algorithms）。
- **掌握标准 / Mastery**：准确完成含进位/借位的三位数加减。
- **例子 / Example**：456+278=734；503−167=336。

### 2.3 一位数乘整十数 / Multiply One-Digit by Multiples of 10
- **学什么 / What**：用位值与性质计算一位数乘 10–90（multiples of 10）。
- **掌握标准 / Mastery**：能解释 9×80=9×8×10=720。
- **例子 / Example**：7×60=420。

## 3. 分数 / Number & Operations—Fractions

### 3.1 理解单位分数 1/b 与 a/b / Understand Unit Fractions
- **学什么 / What**：1/b 是整体平均分成 b 份中的 1 份（unit fraction）；a/b 是 a 个 1/b。
- **掌握标准 / Mastery**：能用图形表示并说出分子分母含义。
- **例子 / Example**：3/4 = 3 个 1/4。

### 3.2 数轴上的分数 / Fractions on the Number Line
- **学什么 / What**：把 0 到 1 平均分成 b 段，端点定位 1/b 与 a/b。
- **掌握标准 / Mastery**：能在数轴上标出 2/3 的位置。
- **例子 / Example**：在 0–1 间分 3 段，第 2 个分点是 2/3。

### 3.3 等值分数 / Equivalent Fractions
- **学什么 / What**：识别简单等值分数（equivalent fractions）并用模型/数轴解释为何相等。
- **掌握标准 / Mastery**：能说明 1/2 = 2/4。
- **例子 / Example**：1/2、2/4、3/6 指向数轴同一点。

### 3.4 比较分数 / Compare Fractions
- **学什么 / What**：比较同分子或同分母的两个分数（same numerator or same denominator），用 >、=、< 并需同一整体。
- **掌握标准 / Mastery**：能解释 3/8 < 5/8（同分母看分子）、1/3 > 1/4（同分子看分母）。
- **例子 / Example**：2/3 vs 2/5 → 2/3 更大。

### 3.5 整数表示成分数 / Whole Numbers as Fractions
- **学什么 / What**：把整数写成分数（3 = 3/1），在数轴上找到与整数重合的分数（4/4=1）。
- **掌握标准 / Mastery**：能识别 6/2=3。
- **例子 / Example**：1 = 4/4 = 2/2。

## 4. 测量与数据 / Measurement & Data

### 4.1 读时间与经过时间 / Time to the Minute
- **学什么 / What**：把时间读写到分钟（to the nearest minute）；在数轴上解经过时间（elapsed time）的加减分钟问题。
- **掌握标准 / Mastery**：能算出 8:15 到 8:50 经过 35 分钟。
- **例子 / Example**：活动 8:15 开始，持续 35 分钟，9:00? 不，8:50 结束。

### 4.2 液体体积与质量 / Liquid Volume & Mass
- **学什么 / What**：估测与测量液体体积和物体质量，单位克(g)、千克(kg)、升(L)；用四则运算解同单位应用题。
- **掌握标准 / Mastery**：能选合适单位并计算。
- **例子 / Example**：一瓶水 2 L，倒入 4 杯，每杯几 mL（用 L 思考）。

### 4.3 象形图与条形图 / Picture & Bar Graphs
- **学什么 / What**：画带刻度（scaled）的象形图和条形图表示多类数据；解"多/少几个"与"一共"等问题。
- **掌握标准 / Mastery**：能读懂一格代表 5 个的图。
- **例子 / Example**：象形图中 1 个图标=5 本书，4 个图标=20 本。

### 4.4 测量长度与折线图 / Measure Length & Line Plot
- **学什么 / What**：量长度到 1/2、1/4 英寸（half/quarter inch），把数据做成折线图（line plot），横轴标 1/2、1/4 刻度。
- **掌握标准 / Mastery**：能把多个测量值正确点在折线图上。
- **例子 / Example**：测 10 支铅笔长度并作图。

### 4.5 面积 / Area
- **学什么 / What**：面积是单位正方形（unit square）覆盖；通过计数和相乘求面积；用分配律（a×(b+c)）与可加性（additivity，拼接区域相加）求复杂图形面积。
- **掌握标准 / Mastery**：能用乘法求矩形面积并解释边长×边长。
- **例子 / Example**：4×6 矩形面积 24 平方单位；L 形 = 两个矩形面积相加。

### 4.6 周长 / Perimeter
- **学什么 / What**：求多边形周长（perimeter）；已知周长求未知边长；探究同周长不同面积、同面积不同周长（same perimeter different area）。
- **掌握标准 / Mastery**：能用总周长与已知边反求未知边。
- **例子 / Example**：周长 20、三边 4/5/6，第四边 5。

## 5. 几何 / Geometry

### 5.1 四边形分类 / Classify Quadrilaterals
- **学什么 / What**：按属性归类四边形；理解菱形(rhombus)、矩形(rectangle)、正方形(square)是有共同属性的类别（如四边形），正方形是矩形也是菱形的特例。
- **掌握标准 / Mastery**：能画出不属于任一已知子类的四边形。
- **例子 / Example**：正方形既是矩形又是菱形。

### 5.2 等面积分割 / Partition into Equal Areas
- **学什么 / What**：把图形分成面积相等的部分，用单位分数表示每部分面积（unit fraction of the whole）。
- **掌握标准 / Mastery**：能说出 4 等分中每份是 1/4。
- **例子 / Example**：长方形分 6 等份，每份面积是整体的 1/6。

## 游戏化玩法建议 / Gamification Hooks
- **运算与代数思维 / OA**：乘法表"闯关塔"，每层一个数的乘法事实，限时答题积星，年底解锁"全表大师"徽章。
- **十进制数与运算 / NBT**：四舍五入"过山车"，数字滑到刻度线时玩家拨杆决定上下取整，落错站扣分。
- **分数 / Fractions**：数轴"跳格寻宝"，玩家把青蛙跳到 2/3 等正确分点，等值分数则是隐藏的"同一格"宝箱。
- **测量与数据 / MD**：经营"果汁店"，玩家用克/升计量配方，并用条形图统计当日销量解锁新口味。
- **面积与周长 / Area & Perimeter**：用方块"造房子"，给定面积造尽可能多形状，比较谁用的围墙(周长)最短。
- **几何 / Geometry**：四边形"家族分类"传送带，把滑过的图形丢进正确的家族桶（矩形/菱形/正方形）。
