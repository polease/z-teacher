# 三年级 · 社会研究 / Grade 3 · Social Studies

> 对齐标准：三年级「远近社区与世界社区」主题（同心圆课程第三层，World Communities）。本年级把视野从本地社区扩展到世界各地的社区。

## 本年级总目标 / Year Goals
本学年学生将学习地图与地理工具，比较世界各地社区的文化与生活方式。
Students will learn maps and geography tools and compare cultures and ways of life in communities around the world.
学生将了解社区的历史变迁、三级政府与公民责任。
Students will explore how communities change over time, the three levels of government, and citizen responsibilities.
学生还将认识基本经济概念，理解人们如何满足需要与想要。
Students will learn basic economic concepts and how people meet needs and wants.

## 1. 地理 / Geography

### 1.1 地图与地球仪 / Maps & Globes
- **学什么 / What**：使用地图与地球仪，认识经度、纬度入门（latitude and longitude）、指南针方向。
- **掌握标准 / Mastery**：能用图例、比例尺、方向找到位置。
- **例子 / Example**：用网格线大致说出某城市在地图上的位置。

### 1.2 半球与区域 / Hemispheres & Regions
- **学什么 / What**：理解半球（hemispheres）和区域（regions）的划分。
- **掌握标准 / Mastery**：能识别南北半球、东西半球与七大洲。
- **例子 / Example**：赤道把地球分成北半球和南半球。

### 1.3 自然与人文地理 / Physical & Human Geography
- **学什么 / What**：区分自然特征（physical features：山、河、海）与人文特征（human features：城市、道路）。
- **掌握标准 / Mastery**：能在地图上分类标出两类特征。
- **例子 / Example**：山脉是自然特征，桥梁是人文特征。

### 1.4 环境与人 / Human-Environment Interaction
- **学什么 / What**：理解人如何适应与改变环境（adapt and modify environment）。
- **掌握标准 / Mastery**：能举例说明人地相互影响。
- **例子 / Example**：人们在寒冷地区盖厚墙保暖、修水坝引水灌溉。

## 2. 世界各地社区 / World Communities

### 2.1 比较不同文化 / Compare Cultures
- **学什么 / What**：比较世界不同地区社区的文化（cultures）与生活方式。
- **掌握标准 / Mastery**：能找出不同文化的相同与不同点。
- **例子 / Example**：比较日本与墨西哥的食物、服饰、节日。

### 2.2 城市、郊区与乡村 / Urban, Suburban & Rural
- **学什么 / What**：区分全球的城市、郊区、乡村社区（urban, suburban, rural）。
- **掌握标准 / Mastery**：能说明三类社区在人口、建筑、工作上的差异。
- **例子 / Example**：城市高楼林立、人多；乡村以农田为主。

### 2.3 满足基本需要的不同方式 / Meeting Needs Differently
- **学什么 / What**：不同社区用不同方式满足食物、住所、衣着等需要。
- **掌握标准 / Mastery**：能说明地理环境如何影响生活方式。
- **例子 / Example**：临海社区以捕鱼为生，草原社区以放牧为生。

## 3. 地方与社区历史 / Local & Community History

### 3.1 社区如何变化 / How Communities Change
- **学什么 / What**：了解社区随时间发生的变化（change over time）。
- **掌握标准 / Mastery**：能用「过去与现在」对比社区。
- **例子 / Example**：从前是农田的地方现在是商场。

### 3.2 社区的创建者 / Community Founders
- **学什么 / What**：认识建立与塑造社区的重要人物（founders）。
- **掌握标准 / Mastery**：能说出本地或某社区创建者的贡献。
- **例子 / Example**：早期移民如何建立第一所学校或市场。

### 3.3 移民 / Immigration
- **学什么 / What**：理解移民（immigration）如何丰富社区的人口与文化。
- **掌握标准 / Mastery**：能说明移民带来的文化与技能。
- **例子 / Example**：不同国家的移民带来了各自的美食与节日。

## 4. 政府与公民 / Government & Citizenship

### 4.1 三级政府 / Three Levels of Government
- **学什么 / What**：认识地方、州、国家三级政府（local, state, national）。
- **掌握标准 / Mastery**：能说出各级政府的主要职责。
- **例子 / Example**：市政府管垃圾收集，国家政府管军队。

### 4.2 民主 / Democracy
- **学什么 / What**：理解民主（democracy）中人民通过投票做决定。
- **掌握标准 / Mastery**：能说明投票与多数原则。
- **例子 / Example**：班级投票选出春游地点。

### 4.3 权利与责任 / Rights & Responsibilities
- **学什么 / What**：了解公民的权利（rights）与责任（responsibilities）。
- **掌握标准 / Mastery**：能区分权利与责任并举例。
- **例子 / Example**：有发言的权利，也有遵守规则的责任。

### 4.4 公民参与 / Civic Participation
- **学什么 / What**：理解公民如何参与社区（civic participation）。
- **掌握标准 / Mastery**：能提出参与社区的方式。
- **例子 / Example**：参加社区清洁、投票、志愿服务。

## 5. 经济 / Economics

### 5.1 需要与想要 / Needs & Wants
- **学什么 / What**：区分需要（needs）和想要（wants）。
- **掌握标准 / Mastery**：能把物品分类为需要或想要。
- **例子 / Example**：食物是需要，玩具是想要。

### 5.2 商品与服务 / Goods & Services
- **学什么 / What**：区分商品（goods）和服务（services）。
- **掌握标准 / Mastery**：能举例并分类。
- **例子 / Example**：面包是商品，理发是服务。

### 5.3 生产者与消费者 / Producers & Consumers
- **学什么 / What**：理解生产者（producers）与消费者（consumers）的角色。
- **掌握标准 / Mastery**：能说明同一个人何时是生产者、何时是消费者。
- **例子 / Example**：农民生产蔬菜，顾客购买蔬菜。

### 5.4 供需入门 / Supply & Demand
- **学什么 / What**：初步理解供给与需求（supply and demand）如何影响价格。
- **掌握标准 / Mastery**：能说明稀缺时价格上升。
- **例子 / Example**：玩具很受欢迎而数量少时，价格会更高。

### 5.5 贸易 / Trade
- **学什么 / What**：理解人们通过贸易（trade）交换商品与服务。
- **掌握标准 / Mastery**：能说明贸易让双方都得到所需。
- **例子 / Example**：一个社区用粮食换另一个社区的布料。

### 5.6 分工 / Division of Labor
- **学什么 / What**：理解分工（division of labor）能提高效率。
- **掌握标准 / Mastery**：能说明专门做一件事的好处。
- **例子 / Example**：面包店里有人和面、有人烤、有人卖。

### 5.7 货币 / Money
- **学什么 / What**：理解货币（money）作为交换媒介的作用。
- **掌握标准 / Mastery**：能说明货币比以物易物更方便。
- **例子 / Example**：用钱买东西比用鸡蛋换东西更通用。

## 6. 文化 / Culture

### 6.1 传统与节日 / Traditions & Festivals
- **学什么 / What**：了解世界各地的传统（traditions）和节日（festivals）。
- **掌握标准 / Mastery**：能描述某节日的来历与庆祝方式。
- **例子 / Example**：中国春节、印度排灯节、美国感恩节。

### 6.2 信仰与价值观 / Beliefs & Values
- **学什么 / What**：认识不同文化的信仰（beliefs）与价值观。
- **掌握标准 / Mastery**：能尊重并描述不同信仰。
- **例子 / Example**：不同文化对家庭、长辈有各自的看法。

### 6.3 多样性 / Diversity
- **学什么 / What**：理解社区的文化多样性（diversity）。
- **掌握标准 / Mastery**：能说明多样性带来的好处。
- **例子 / Example**：班里同学来自不同国家，分享各自的故事。

### 6.4 文化贡献 / Cultural Contributions
- **学什么 / What**：认识各文化对世界的贡献（contributions），如食物、音乐、发明。
- **掌握标准 / Mastery**：能举例说明某文化的贡献。
- **例子 / Example**：意大利的比萨、非洲的鼓乐、中国的造纸术。

## 游戏化玩法建议 / Gamification Hooks
- **地理 / Geography**：「环球定位」用经纬度/半球线索在地图上找到目标城市闯关。
- **世界社区 / World Communities**：「文化护照」走访不同国家社区，收集文化印章解锁徽章。
- **历史 / History**：「时间拼图」把社区的过去与现在照片配对，排出变化时间线。
- **政府公民 / Government**：「市长一日」做出市政决策并组织班级投票体验民主。
- **经济 / Economics**：「迷你市场」当生产者与消费者，用货币买卖体验供需与贸易。
- **文化 / Culture**：「节日嘉年华」匹配节日、食物与来源国，介绍一项文化贡献得分。
