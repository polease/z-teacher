# 二年级 · 英语语言艺术 / Grade 2 · English Language Arts

> 对齐标准：美国共同核心标准 Common Core State Standards for ELA (Grade 2)。本年级强化拼读与流利度，发展文学与信息类阅读的理解，并系统训练写作、口语与语言规范。

## 本年级总目标 / Year Goals
学生将巩固拼读（长元音、元音组合、前后缀）并能带着表情和理解流利朗读、自我纠正。
Students consolidate phonics (long vowels, vowel teams, affixes) and read fluently with expression, comprehension, and self-correction.
学生能复述故事并提炼寓意、确定文本主旨、使用文本特征，并撰写观点、说明与记叙三类文章。
Students retell stories and find their lessons, determine main ideas, use text features, and write opinion, informative, and narrative pieces.

## 1. 基础阅读技能 / Foundational Skills

### 1.1 长元音拼写 / Long Vowel Spellings
- **学什么 / What**：识读常见长元音拼写模式（long vowels），如 a_e, i_e, o_e。
- **掌握标准 / Mastery**：能准确拼读规则长元音单词。
- **例子 / Example**：cake, ride, hope, cute。

### 1.2 元音组合 / Vowel Teams
- **学什么 / What**：识读元音组合（vowel teams）如 ai, ea, oa, ee, ay。
- **掌握标准 / Mastery**：能根据组合发对元音。
- **例子 / Example**：rain, beach, boat, tree, play。

### 1.3 含长元音的两音节词 / Two-Syllable Words with Long Vowels
- **学什么 / What**：拆读包含长元音的两音节词（two-syllable words）。
- **掌握标准 / Mastery**：能按音节拆分并连读。
- **例子 / Example**：tiger（ti-ger）, paper（pa-per）, table（ta-ble）。

### 1.4 前缀与后缀 / Prefixes & Suffixes
- **学什么 / What**：识读带常见前缀和后缀的单词（prefixes, suffixes）。
- **掌握标准 / Mastery**：能拆出词根并读出整词。
- **例子 / Example**：reread, unhappy, helpful, jumping。

### 1.5 不规则拼写词 / Irregularly Spelled Words
- **学什么 / What**：认读常见不规则拼写的高频词（sight words）。
- **掌握标准 / Mastery**：能整体识别、不靠拼读。
- **例子 / Example**：said, could, again, because。

### 1.6 流利朗读与自我纠正 / Fluent Reading & Self-Correction
- **学什么 / What**：带表情、适当速度和理解地朗读，遇错能自我纠正、重读确认（fluency, self-correct）。
- **掌握标准 / Mastery**：朗读准确、有语调、能在读错时回头改正。
- **例子 / Example**：读到「I can't believe it!」时提高语气，读错单词后停下重读。

## 2. 文学类阅读 / Reading Literature

### 2.1 回答 5W1H / Answering Who/What/Where/When/Why/How
- **学什么 / What**：就故事关键细节回答 who、what、where、when、why、how。
- **掌握标准 / Mastery**：能从文本中找证据作答。
- **例子 / Example**：「小兔为什么哭？」因为它的胡萝卜丢了。

### 2.2 复述故事与提炼寓意 / Retelling Stories & Finding the Lesson
- **学什么 / What**：复述故事，包括来自不同文化的寓言和民间故事（fables, folktales），并说出寓意或主旨（central message/moral）。
- **掌握标准 / Mastery**：能按序复述并总结教训。
- **例子 / Example**：复述《龟兔赛跑》并说出「坚持比骄傲更重要」。

### 2.3 角色如何回应事件 / How Characters Respond to Events
- **学什么 / What**：描述角色如何回应主要事件与挑战（characters respond）。
- **掌握标准 / Mastery**：能说明角色的行动与感受变化。
- **例子 / Example**：比赛落后时，乌龟依然坚持前行。

### 2.4 故事结构 / Story Structure
- **学什么 / What**：识别故事的开头、中间、结尾（beginning, middle, end），明白开头引入、结尾收束。
- **掌握标准 / Mastery**：能把故事分成三部分。
- **例子 / Example**：开头介绍角色，中间发生冲突，结尾问题解决。

### 2.5 不同角色用不同语气 / Voices for Different Characters
- **学什么 / What**：朗读对话时为不同角色使用不同声音和语气（point of view, voice）。
- **掌握标准 / Mastery**：能用语气区分说话人。
- **例子 / Example**：大熊用低沉声音，小老鼠用细高声音。

### 2.6 插图与文字配合 / Illustrations & Words Together
- **学什么 / What**：利用插图与文字共同理解角色、情节与环境（illustrations）。
- **掌握标准 / Mastery**：能从图中补充文字未明说的信息。
- **例子 / Example**：图中乌云说明故事发生在雨天。

### 2.7 比较同一故事的两个版本 / Comparing Two Versions of a Story
- **学什么 / What**：比较同一故事（如灰姑娘）的不同版本（compare versions）。
- **掌握标准 / Mastery**：能说出相同点与不同点。
- **例子 / Example**：两个版本的结局或人物不同。

## 3. 信息类阅读 / Reading Informational

### 3.1 主旨与各段焦点 / Main Idea & Focus of Paragraphs
- **学什么 / What**：确定多段文本的主旨以及各段的具体焦点（main idea, focus）。
- **掌握标准 / Mastery**：能区分整体主旨与段落要点。
- **例子 / Example**：全文讲蜜蜂，某段专讲蜜蜂如何采蜜。

### 3.2 事件与概念的联系 / Connections Between Events & Ideas
- **学什么 / What**：描述历史、科学或技术文本中事件、步骤、概念间的联系（connections）。
- **掌握标准 / Mastery**：能说明先后或因果关系。
- **例子 / Example**：种子先发芽，然后长出叶子。

### 3.3 词义 / Word Meaning
- **学什么 / What**：确定二年级主题或学科文本中词语的意思（word meaning）。
- **掌握标准 / Mastery**：能借助上下文理解关键词。
- **例子 / Example**：在科普文中理解「栖息地」一词。

### 3.4 文本特征 / Text Features
- **学什么 / What**：使用图注、加粗字、小标题、词汇表、索引等文本特征快速定位信息（captions, bold, subheadings, glossary, index）。
- **掌握标准 / Mastery**：能用某个特征找到所需信息。
- **例子 / Example**：用索引找到「火山」所在页码。

### 3.5 图片的用途 / Purpose of Images
- **学什么 / What**：说明图片如何帮助说明文本（images）。
- **掌握标准 / Mastery**：能解释图片提供的信息。
- **例子 / Example**：流程图展示蝴蝶生命周期。

### 3.6 作者目的与理由 / Author's Purpose & Reasons
- **学什么 / What**：找出作者想要说明的要点及其支持的理由（author's purpose, reasons）。
- **掌握标准 / Mastery**：能指出主张及对应理由。
- **例子 / Example**：作者认为「应多运动」，理由是运动让身体强壮。

### 3.7 比较同主题两篇文本 / Comparing Two Texts on Same Topic
- **学什么 / What**：比较关于同一主题的两篇文本所呈现的要点（compare texts）。
- **掌握标准 / Mastery**：能找出相同与不同信息。
- **例子 / Example**：两篇关于狗的文章，一篇讲品种，一篇讲训练。

## 4. 写作 / Writing

### 4.1 观点类写作 / Opinion Writing
- **学什么 / What**：写观点文，包含引入话题、陈述观点、提供理由、用连接词（because, and, also）连接、写出结论（opinion, reasons, linking words, conclusion）。
- **掌握标准 / Mastery**：结构完整、理由清楚。
- **例子 / Example**：「我最喜欢的季节是夏天，因为可以游泳，也因为白天长。」

### 4.2 说明类写作 / Informative Writing
- **学什么 / What**：写说明文，介绍主题、给出事实与定义、写出结尾（informative/explanatory）。
- **掌握标准 / Mastery**：信息准确、围绕主题。
- **例子 / Example**：介绍「企鹅住在哪里、吃什么」。

### 4.3 记叙类写作 / Narrative Writing
- **学什么 / What**：写带细节和先后顺序的记叙文，包含事件、想法、感受和结尾（narrative, sequence, details）。
- **掌握标准 / Mastery**：事件按序、细节生动。
- **例子 / Example**：「先……然后……最后……」叙述一次郊游。

### 4.4 在指导下修改 / Revising with Guidance
- **学什么 / What**：在大人和同伴的帮助下修改、润色写作（revise, edit）。
- **掌握标准 / Mastery**：能根据反馈增删细节、改正错误。
- **例子 / Example**：添加描述词、修正标点后重写一句。

### 4.5 共享研究项目 / Shared Research Projects
- **学什么 / What**：参与共享的研究与写作项目，从提供的资料中收集信息（shared research）。
- **掌握标准 / Mastery**：能记录信息并合作完成报告。
- **例子 / Example**：全班一起研究「我们社区的鸟」并制作小册子。

## 5. 口语与倾听 / Speaking & Listening

### 5.1 对话中接续他人 / Building on Others in Conversation
- **学什么 / What**：在对话中遵守规则、接续他人话题（build on conversation）。
- **掌握标准 / Mastery**：能轮流发言、回应同伴。
- **例子 / Example**：「我同意你说的，还想补充……」

### 5.2 复述关键信息 / Recounting Key Information
- **学什么 / What**：复述朗读文本或媒体中呈现的关键信息（recount key ideas）。
- **掌握标准 / Mastery**：能说出主要内容。
- **例子 / Example**：听完故事后说出主要人物和事件。

### 5.3 提问澄清 / Asking Clarifying Questions
- **学什么 / What**：提出问题以澄清不理解之处（clarify）。
- **掌握标准 / Mastery**：能提出有针对性的问题。
- **例子 / Example**：「你说的『迁徙』是什么意思？」

### 5.4 带细节讲述 / Telling Stories with Details
- **学什么 / What**：讲述故事或经历时加入相关事实细节，吐字清楚（facts and details）。
- **掌握标准 / Mastery**：表达连贯、细节相关。
- **例子 / Example**：讲述周末去公园看到了什么。

### 5.5 说完整句 / Speaking in Complete Sentences
- **学什么 / What**：在合适场合用完整句表达（complete sentences）。
- **掌握标准 / Mastery**：句子有主语和谓语、意思完整。
- **例子 / Example**：不说「红色」，而说「我最喜欢红色」。

## 6. 语言规范 / Language

### 6.1 大写规则 / Capitalization
- **学什么 / What**：节日、产品名、地名等专有名词要大写（capitalization）。
- **掌握标准 / Mastery**：能在写作中正确大写。
- **例子 / Example**：Christmas, Lego, New York。

### 6.2 逗号用法 / Commas
- **学什么 / What**：信件的问候语和结尾使用逗号（commas in greetings and closings）。
- **掌握标准 / Mastery**：能在信中正确加逗号。
- **例子 / Example**：Dear Mom, ... Love, Tom。

### 6.3 撇号 / Apostrophes
- **学什么 / What**：用撇号表示缩写和所有格（contractions, possessives）。
- **掌握标准 / Mastery**：能区分两种用法。
- **例子 / Example**：don't（缩写），Sara's book（所有格）。

### 6.4 拼写规律 / Spelling Patterns
- **学什么 / What**：运用拼写规律和高频词拼写单词（spelling patterns）。
- **掌握标准 / Mastery**：常用词拼写正确。
- **例子 / Example**：cage → cages，badge 中的 dge。

### 6.5 集合名词 / Collective Nouns
- **学什么 / What**：使用集合名词（collective nouns）。
- **掌握标准 / Mastery**：能在句中正确使用。
- **例子 / Example**：group, team, family。

### 6.6 不规则复数 / Irregular Plurals
- **学什么 / What**：使用常见的不规则复数名词（irregular plural nouns）。
- **掌握标准 / Mastery**：能说出正确复数形式。
- **例子 / Example**：foot → feet，child → children，mouse → mice。

### 6.7 反身代词 / Reflexive Pronouns
- **学什么 / What**：使用反身代词（reflexive pronouns）。
- **掌握标准 / Mastery**：能正确搭配主语。
- **例子 / Example**：myself, yourself, themselves。

### 6.8 不规则过去式 / Irregular Past Tense
- **学什么 / What**：使用常见动词的不规则过去式（irregular past tense verbs）。
- **掌握标准 / Mastery**：能说出正确过去式。
- **例子 / Example**：go → went，eat → ate，hide → hid。

### 6.9 形容词与副词 / Adjectives & Adverbs
- **学什么 / What**：区分并使用形容词和副词（adjectives, adverbs）。
- **掌握标准 / Mastery**：能根据修饰对象选择。
- **例子 / Example**：a quick runner（形容词），runs quickly（副词）。

### 6.10 扩展与重组句子 / Expanding & Rearranging Sentences
- **学什么 / What**：扩展、重组完整的简单句和复合句（produce and expand sentences）。
- **掌握标准 / Mastery**：能根据需要改写句子。
- **例子 / Example**：把「The boy watched the movie.」扩展为「The boy watched the movie at the theater.」

### 6.11 复合词 / Compound Words
- **学什么 / What**：理解并使用复合词，借助拆分理解词义（compound words）。
- **掌握标准 / Mastery**：能拆出两部分推测意思。
- **例子 / Example**：birdhouse = bird + house。

### 6.12 查字典 / Using Dictionaries
- **学什么 / What**：用纸质或电子字典/词汇表查找单词意思（dictionary, glossary）。
- **掌握标准 / Mastery**：能找到词条并理解释义。
- **例子 / Example**：查「habitat」确认意思是「栖息地」。

## 游戏化玩法建议 / Gamification Hooks
- **基础阅读技能 / Foundational Skills**：「拼读飞船」给出元音组合或长元音拼写，玩家点对发音才能让飞船前进；高频词做成「快闪卡片」连对加速。
- **文学类阅读 / Reading Literature**：「故事三宝箱」把句子拖进开头/中间/结尾三个箱子；为角色「配音换装」按语气选择正确声音。
- **信息类阅读 / Reading Informational**：「文本寻宝」要求用索引或小标题在限定页内找信息；「主张配理由」把理由连到正确的作者主张。
- **写作 / Writing**：「观点搭建塔」按引入→理由→连接词→结论一层层垒积木，结构完整才稳。
- **口语与倾听 / Speaking & Listening**：「接话龙」每人必须接上一句继续故事；「问个清楚」录音提问，问题切题得分。
- **语言规范 / Language**：「标点医生」修复缺失的大写、逗号、撇号；「复数变形怪」给不规则名词选对复数。
