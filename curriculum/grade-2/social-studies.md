# 二年级 · 社会研究 / Grade 2 · Social Studies

> 对齐标准：美国二年级社会研究「邻里与社区」主题，属于「同心圆」(expanding communities) 的第二层。本年级把视野从家庭与学校扩展到所在的社区。

## 本年级总目标 / Year Goals
学生将认识不同类型的社区、社区中的服务者与地方政府，并理解作为公民的权利与责任。
Students learn about types of communities, community helpers and local government, and understand their rights and responsibilities as citizens.
学生还将入门地图与地理工具、基本经济概念，以及社区如何随时间变化的历史。
Students also begin using maps and geography tools, learn basic economic ideas, and explore how communities change over time.

## 1. 社区 / Community

### 1.1 社区类型 / Types of Communities
- **学什么 / What**：区分城市、郊区和乡村三种社区（urban, suburban, rural）。
- **掌握标准 / Mastery**：能说出每类社区的特点。
- **例子 / Example**：城市高楼多、人口密；乡村农田广、住户分散。

### 1.2 社区服务者与服务 / Community Helpers & Services
- **学什么 / What**：认识社区服务者及其提供的服务（community helpers, services）。
- **掌握标准 / Mastery**：能把服务者与其工作配对。
- **例子 / Example**：消防员灭火、医生看病、邮递员送信。

### 1.3 社区地标 / Community Landmarks
- **学什么 / What**：识别社区中的重要地标（landmarks）。
- **掌握标准 / Mastery**：能说出地标的作用。
- **例子 / Example**：图书馆、消防站、公园、市政厅。

## 2. 政府 / Government

### 2.1 地方政府的角色 / Role of Local Government
- **学什么 / What**：了解地方政府为社区做什么（local government）。
- **掌握标准 / Mastery**：能举出政府提供的公共服务。
- **例子 / Example**：修路、办学校、收垃圾、保护安全。

### 2.2 市长与领导 / Mayors & Leaders
- **学什么 / What**：认识市长等社区领导及其职责（mayor, leaders）。
- **掌握标准 / Mastery**：能说出领导做什么。
- **例子 / Example**：市长帮助为城市做决定、主持会议。

### 2.3 制定规则与法律 / Making Rules & Laws
- **学什么 / What**：理解为什么需要规则和法律，以及它们如何制定（rules, laws）。
- **掌握标准 / Mastery**：能说明规则带来的好处。
- **例子 / Example**：红绿灯法律让交通更安全。

### 2.4 投票入门 / Introduction to Voting
- **学什么 / What**：了解投票是做集体决定、选领导的方式（voting）。
- **掌握标准 / Mastery**：能说出投票的意义。
- **例子 / Example**：全班投票决定班级吉祥物，多数获胜。

## 3. 公民素养 / Citizenship

### 3.1 权利与责任 / Rights & Responsibilities
- **学什么 / What**：理解公民的权利与责任（rights, responsibilities）。
- **掌握标准 / Mastery**：能各举一例。
- **例子 / Example**：有权上学（权利）；要遵守规则、爱护环境（责任）。

### 3.2 解决问题 / Solving Problems
- **学什么 / What**：学习在社区中合作解决问题（problem solving）。
- **掌握标准 / Mastery**：能提出公平的解决办法。
- **例子 / Example**：操场太挤，大家商量轮流使用。

### 3.3 社区中的多样性 / Diversity in the Community
- **学什么 / What**：认识并尊重社区中的多样性（diversity）。
- **掌握标准 / Mastery**：能说出人们有哪些不同并予以尊重。
- **例子 / Example**：不同家庭有不同语言、节日和食物。

## 4. 地理 / Geography

### 4.1 七大洲四大洋 / Seven Continents & Four Oceans
- **学什么 / What**：入门认识地球上的七大洲和四大洋（continents, oceans）。
- **掌握标准 / Mastery**：能在地图或地球仪上指出几个洲与洋。
- **例子 / Example**：亚洲、北美洲；太平洋、大西洋。

### 4.2 指南针玫瑰 / Compass Rose
- **学什么 / What**：用指南针玫瑰辨认东、南、西、北方向（compass rose, cardinal directions）。
- **掌握标准 / Mastery**：能用方向词描述位置。
- **例子 / Example**：图书馆在学校的北边。

### 4.3 地图图例 / Map Legends
- **学什么 / What**：读懂地图图例中的符号（legend, symbols）。
- **掌握标准 / Mastery**：能用图例解读地图。
- **例子 / Example**：树形符号表示公园，蓝色表示水。

### 4.4 自然与人文特征 / Physical & Human Features
- **学什么 / What**：区分自然特征与人文特征（physical and human features）。
- **掌握标准 / Mastery**：能把特征分类。
- **例子 / Example**：山、河是自然特征；桥、楼房是人文特征。

### 4.5 描述位置 / Describing Location
- **学什么 / What**：用方位词描述地点的相对位置（location）。
- **掌握标准 / Mastery**：能说出某地相对另一地的位置。
- **例子 / Example**：超市在公园旁边、邮局对面。

## 5. 经济 / Economics

### 5.1 商品与服务 / Goods & Services
- **学什么 / What**：区分商品（物品）与服务（行为）（goods, services）。
- **掌握标准 / Mastery**：能把例子归类。
- **例子 / Example**：面包是商品，理发是服务。

### 5.2 生产者与消费者 / Producers & Consumers
- **学什么 / What**：认识生产者制造、消费者购买（producers, consumers）。
- **掌握标准 / Mastery**：能分辨谁是生产者、谁是消费者。
- **例子 / Example**：农民生产蔬菜，顾客购买蔬菜。

### 5.3 需要与想要 / Needs & Wants
- **学什么 / What**：区分生活必需的「需要」和非必需的「想要」（needs, wants）。
- **掌握标准 / Mastery**：能正确归类。
- **例子 / Example**：食物和水是需要；玩具和糖果是想要。

### 5.4 稀缺 / Scarcity
- **学什么 / What**：理解资源有限就会出现稀缺，需要做选择（scarcity, choices）。
- **掌握标准 / Mastery**：能说明稀缺为何要做取舍。
- **例子 / Example**：钱有限，只能在两件玩具中选一个。

### 5.5 货币与交易 / Money & Trade
- **学什么 / What**：了解货币用于买卖，过去人们也用以物易物（money, trade, barter）。
- **掌握标准 / Mastery**：能说明货币如何让交易更方便。
- **例子 / Example**：用钱买文具；古时用粮食换布。

### 5.6 社区里的工作 / Jobs in the Community
- **学什么 / What**：认识社区中各种工作及其作用（jobs）。
- **掌握标准 / Mastery**：能说出几种工作及贡献。
- **例子 / Example**：面包师做面包，公交司机送大家上班。

## 6. 历史 / History

### 6.1 社区历史 / Community History
- **学什么 / What**：了解社区过去的样子（community history）。
- **掌握标准 / Mastery**：能说出社区今昔的不同。
- **例子 / Example**：以前是农田的地方现在建起了学校。

### 6.2 随时间的变化 / Changes Over Time
- **学什么 / What**：观察事物随时间发生的变化（change over time）。
- **掌握标准 / Mastery**：能比较过去与现在。
- **例子 / Example**：交通工具从马车变成汽车。

### 6.3 历史人物 / Historical Figures
- **学什么 / What**：认识对社区或国家有贡献的历史人物（historical figures）。
- **掌握标准 / Mastery**：能说出人物的贡献。
- **例子 / Example**：纪念为社区做出贡献的创始人或英雄。

### 6.4 时间线 / Timelines
- **学什么 / What**：用时间线把事件按先后排列（timeline, sequence）。
- **掌握标准 / Mastery**：能把事件按时间顺序放好。
- **例子 / Example**：把「出生—上学—现在」排成一条时间线。

### 6.5 原始资料入门 / Introduction to Primary Sources
- **学什么 / What**：认识照片、信件、实物等原始资料能告诉我们过去（primary sources）。
- **掌握标准 / Mastery**：能说出一种原始资料及它能告诉我们什么。
- **例子 / Example**：旧照片显示从前的街道样子。

## 游戏化玩法建议 / Gamification Hooks
- **社区 / Community**：「社区拼图」把城市/郊区/乡村的元素拖到正确社区；「服务者配对」连线服务者与其工作。
- **政府 / Government**：「市长的一天」做角色扮演决策，制定规则解决社区问题；「投票站」班级问题用投票决出多数。
- **公民素养 / Citizenship**：「权利还是责任」分类卡片；「化解冲突」选出最公平的解决方案。
- **地理 / Geography**：「指南针寻宝」按东南西北方向走到目标；「地图侦探」用图例和方向找出地点。
- **经济 / Economics**：「小小商店」扮演生产者和消费者用货币交易，遇到稀缺要取舍；「需要 vs 想要」快速分拣。
- **历史 / History**：「今昔对比」滑动看同一地点的过去与现在；「时间线大师」把事件卡按顺序排好。
