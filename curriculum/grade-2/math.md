# 二年级 · 数学 / Grade 2 · Mathematics

> 对齐标准：Common Core State Standards for Mathematics, Grade 2 (CCSS-M G2)。二年级数学聚焦于 1000 以内的位值理解、20 以内加减法的流利运用，以及长度测量与基本几何。

## 本年级总目标 / Year Goals
学生能凭记忆熟练完成 20 以内的加减法，理解三位数（最大到 1000）的位值结构，并使用合适的策略进行 100 以内的加减运算。
Students fluently add and subtract within 20 from memory, understand place value of three-digit numbers up to 1000, and use appropriate strategies to add and subtract within 100.
学生还将学会用标准工具测量长度、读时钟到 5 分钟、认识钱币，并识别与拆分基本平面图形。
Students also measure length with standard tools, tell time to the nearest 5 minutes, work with money, and identify and partition basic plane shapes.

## 1. 运算与代数思维 / Operations & Algebraic Thinking

### 1.1 20 以内加减法熟练 / Fluently Add and Subtract Within 20
- **学什么 / What**：用心算策略（凑十 make-a-ten、相关事实 related facts）流利完成 20 以内加减，年底要能凭记忆 (from memory) 说出所有一位数和。
- **掌握标准 / Mastery**：3 秒内正确回答任意 20 以内的加减事实，准确率 ≥ 90%。
- **例子 / Example**：8 + 7 = 15（拆成 8 + 2 + 5）；14 − 6 = 8。

### 1.2 一步应用题 / One-Step Word Problems
- **学什么 / What**：解决 100 以内的加减一步应用题，涵盖加 (adding to)、减 (taking from)、合并 (putting together)、拆分 (taking apart)、比较 (comparing)。
- **掌握标准 / Mastery**：能用画图或方程表示问题并求出正确答案。
- **例子 / Example**：盒子里有 47 颗糖，吃掉 19 颗，还剩多少？47 − 19 = 28。

### 1.3 两步应用题 / Two-Step Word Problems
- **学什么 / What**：解决需要两步运算的 100 以内应用题，用未知数符号表示未知量。
- **掌握标准 / Mastery**：能正确分解为两步并按顺序求解。
- **例子 / Example**：小明有 12 张卡，又买了 8 张，送给朋友 5 张，现在有几张？12 + 8 − 5 = 15。

### 1.4 奇偶数 / Even and Odd Numbers
- **学什么 / What**：判断 20 以内某组物体的个数是奇 (odd) 还是偶 (even)，用两两配对 (pairing) 或两个相等加数验证。
- **掌握标准 / Mastery**：能说明"偶数能两两配对，奇数会剩一个"。
- **例子 / Example**：18 = 9 + 9，是偶数；17 配对后剩 1 个，是奇数。

### 1.5 矩形阵列与重复相加 / Rectangular Arrays and Repeated Addition
- **学什么 / What**：用最多 5×5 的矩形阵列（行 rows / 列 columns）数物体总数，写成等加数相加的式子，作为乘法 (multiplication) 的基础。
- **掌握标准 / Mastery**：能由阵列写出重复相加算式并求和。
- **例子 / Example**：4 行每行 5 个 → 5 + 5 + 5 + 5 = 20。

## 2. 十进制数与运算 / Number & Operations in Base Ten

### 2.1 三位数位值 / Place Value of Three-Digit Numbers
- **学什么 / What**：理解三位数由百 (hundreds)、十 (tens)、个 (ones) 组成；100 是 10 个十，整百数 100–900 是若干个百。
- **掌握标准 / Mastery**：能说出任意三位数中每个数字代表的值。
- **例子 / Example**：347 = 3 个百 + 4 个十 + 7 个个。

### 2.2 1000 以内数数 / Counting Within 1000
- **学什么 / What**：能逐一从任意数数到 1000。
- **掌握标准 / Mastery**：能从给定数继续往上数，不跳不漏。
- **例子 / Example**：从 596 数：596, 597, 598, 599, 600, 601…

### 2.3 按 5、10、100 跳数 / Skip-Count by 5s, 10s, 100s
- **学什么 / What**：在 1000 以内按 5、10、100 跳数 (skip-count)。
- **掌握标准 / Mastery**：能正确报出跳数序列。
- **例子 / Example**：按百跳：100, 200, 300… ；按五跳：5, 10, 15, 20…

### 2.4 读写到 1000 / Read and Write Numbers to 1000
- **学什么 / What**：用数字 (numerals)、名称 (number names) 和展开式 (expanded form) 表示数。
- **掌握标准 / Mastery**：三种形式可互相转换。
- **例子 / Example**：706 = "七百零六" = 700 + 6（展开式）。

### 2.5 比较三位数 / Compare Three-Digit Numbers
- **学什么 / What**：根据百、十、个的位值比较两个三位数，用 >、=、< 表示。
- **掌握标准 / Mastery**：能正确判断大小并写出符号。
- **例子 / Example**：452 > 449，因为十位 5 > 4。

### 2.6 100 以内加减熟练 / Fluently Add and Subtract Within 100
- **学什么 / What**：用基于位值、运算性质、加减关系的策略与算法 (algorithms) 流利计算 100 以内加减。
- **掌握标准 / Mastery**：能正确处理需进位/退位的题目。
- **例子 / Example**：56 + 38 = 94；72 − 47 = 25。

### 2.7 多个两位数相加 / Add Up to Four Two-Digit Numbers
- **学什么 / What**：把最多四个两位数相加。
- **掌握标准 / Mastery**：能正确累加并使用位值策略。
- **例子 / Example**：23 + 14 + 31 + 12 = 80。

### 2.8 1000 以内加减 / Add and Subtract Within 1000
- **学什么 / What**：用具体模型、画图或策略完成 1000 以内加减，理解百加百、十加十、必要时组合或拆分十/百。
- **掌握标准 / Mastery**：能正确计算并解释方法。
- **例子 / Example**：358 + 247 = 605。

### 2.9 心算多/少 10 或 100 / Mentally Add or Subtract 10 or 100
- **学什么 / What**：对 100–900 范围的数心算加减 10 或 100。
- **掌握标准 / Mastery**：不写竖式即可口答。
- **例子 / Example**：450 + 100 = 550；321 − 10 = 311。

### 2.10 解释策略为何成立 / Explain Why Strategies Work
- **学什么 / What**：用位值和运算性质解释加减策略为什么有效。
- **掌握标准 / Mastery**：能口头或画图说明理由。
- **例子 / Example**："因为 7 个个加 5 个个是 12 个，超过 10，所以进 1 到十位。"

## 3. 测量与数据 / Measurement & Data

### 3.1 用工具量长度 / Measure Length with Tools
- **学什么 / What**：选择合适工具（尺 ruler、卷尺、米尺、码尺）量长度，单位为厘米、米、英寸、英尺 (cm, m, in, ft)。
- **掌握标准 / Mastery**：能正确对齐零刻度并读数。
- **例子 / Example**：用厘米尺量铅笔为 14 厘米。

### 3.2 估测长度 / Estimate Lengths
- **学什么 / What**：用厘米、米、英寸、英尺为单位估测长度。
- **掌握标准 / Mastery**：估测值与实测值接近合理范围。
- **例子 / Example**：估计门约 2 米高。

### 3.3 比较长度差 / Compare Length Differences
- **学什么 / What**：用相同单位测量两个物体并求长度差 (difference)。
- **掌握标准 / Mastery**：能算出"长多少"。
- **例子 / Example**：绳子 60 cm，铅笔 14 cm，长 46 cm。

### 3.4 用数轴联系加减与长度 / Number Line for Add/Subtract
- **学什么 / What**：把整数当成数轴 (number line) 上的点，用数轴跳跃表示 100 以内加减。
- **掌握标准 / Mastery**：能在数轴上画出加减过程。
- **例子 / Example**：从 25 向右跳 30 到 55。

### 3.5 读时间到 5 分钟 / Tell Time to Nearest 5 Minutes
- **学什么 / What**：用模拟和数字钟读时间到 5 分钟，区分上午/下午 (a.m./p.m.)。
- **掌握标准 / Mastery**：能正确读出并写下时间。
- **例子 / Example**：时针指 3、分针指 6 → 3:30 p.m.。

### 3.6 钱币 / Money
- **学什么 / What**：认识元与分 (dollars and cents)，使用 $ 和 ¢ 符号，解决涉及硬币和纸币的应用题。
- **掌握标准 / Mastery**：能算出总额与找零。
- **例子 / Example**：2 个 25¢ + 1 个 10¢ = 60¢。

### 3.7 折线图 / Line Plots
- **学什么 / What**：把测量数据画在带整数刻度的折线图 (line plot) 上。
- **掌握标准 / Mastery**：能正确放置数据点并读图。
- **例子 / Example**：把全班铅笔长度标在折线图上。

### 3.8 象形图与条形图 / Picture Graphs and Bar Graphs
- **学什么 / What**：用最多 4 个类别画象形图 (picture graph) 和条形图 (bar graph)，并解答比较类问题。
- **掌握标准 / Mastery**：能读图并回答"多多少/少多少"。
- **例子 / Example**：喜欢苹果的比香蕉多 3 人。

## 4. 几何 / Geometry

### 4.1 按属性识别与画图形 / Recognize and Draw Shapes by Attributes
- **学什么 / What**：根据给定属性（角 angles、面 faces 的数量）识别和画三角形、四边形、五边形、六边形和立方体。
- **掌握标准 / Mastery**：能数出角和面并命名图形。
- **例子 / Example**：五边形有 5 条边 5 个角。

### 4.2 把长方形分成方格 / Partition Rectangle into Squares
- **学什么 / What**：把长方形分成同样大小的方格的行 (rows) 与列 (columns)，数出总数。
- **掌握标准 / Mastery**：能数出方格总数并与重复相加联系。
- **例子 / Example**：3 行 4 列 = 12 个方格。

### 4.3 等分图形 / Partition into Equal Shares
- **学什么 / What**：把圆和长方形分成二分之一 (halves)、三分之一 (thirds)、四分之一 (fourths)，并理解等份不一定形状相同。
- **掌握标准 / Mastery**：能用"两个一半""三个三分之一"等语言描述整体。
- **例子 / Example**：长方形可竖着或斜着分成两个一半，形状不同但都是一半。

## 游戏化玩法建议 / Gamification Hooks
- **运算与代数思维 / OA**："凑十大冒险"——屏幕掉落数字泡泡，玩家拖动两个相加为 10 或目标数的泡泡消除，过关解锁更大数；奇偶数关卡用配对小动物判断奇偶。
- **十进制数与运算 / NBT**："位值塔"——用百/十/个三色积木搭出指定三位数，跳数关卡按 5/10/100 让角色跳格前进，心算 ±10/±100 设为限时电梯升降。
- **测量与数据 / MD**："量量看王国"——拖动虚拟尺测量道具并选对单位，时钟关让玩家拨动指针到目标时刻，钱币关用拖拽硬币凑出正确金额买商品。
- **几何 / Geometry**："切披萨工坊"——把圆形/方形披萨切成等份送给顾客，行列切割关卡数方格数量解锁阵列对应的乘法宝箱。
