# 美国小学 1–5 年级课程知识体系 / U.S. Elementary Curriculum (Grades 1–5)

> 面向「边学边玩」的在线 AI 教育产品，整理美国小学核心四科的逐年级知识点。
> A grade-by-grade knowledge map of the four core U.S. elementary subjects, designed for a learn-by-play online AI education product.

## 1. 范围与依据 / Scope & Standards

本文档覆盖美国小学 **1–5 年级**的 **核心四科 / four core subjects**：

| 学科 / Subject | 英文 | 对齐标准 / Aligned Standard |
| --- | --- | --- |
| 数学 | Mathematics | Common Core State Standards (CCSS-M) |
| 英语语言艺术 | English Language Arts (ELA) | Common Core State Standards (CCSS-ELA) |
| 科学 | Science | Next Generation Science Standards (NGSS) |
| 社会研究 | Social Studies | C3 Framework / "Expanding Communities" 通行序列 |

> 说明 / Note：美国没有全国统一强制课程，各州（甚至各学区）会微调。本文档取**最广泛通行的版本**作为基准，方便产品做标准化内容。社会研究（Social Studies）各州差异最大，1–3 年级普遍采用「由近及远」的同心圆模型（家庭→社区→世界），4–5 年级普遍转向「美国地理 + 美国历史」。

## 3. 五年学习主线 / The 5-Year Learning Arc

一句话看懂每个学科「从 1 年级到 5 年级」是怎么进阶的：

- **数学 Math**：数感与 20 以内加减 → 100/1000 以内运算 → 乘除法与分数入门 → 多位数乘除 + 分数四则 + 小数 → 分数/小数熟练运算 + 体积 + 坐标系。
- **英语 ELA**：拼读解码（phonics）与认字 → 流利阅读 → 多段落阅读理解与写作 → 主题归纳与结构化写作 → 引证文本、跨文本研究与规范写作。
- **科学 Science**：观察现象与模式（光/声/动植物/天空）→ 物质与生态系统 → 力、生命周期、天气 → 能量、波、地球系统 → 物质守恒、生态能量流、地球与太空系统。
- **社会研究 Social Studies**：家庭与学校 → 社区 → 世界各地社区 → 美国地理与区域/州 → 美国早期历史与政府。

## 4. 总览矩阵 / Master Matrix (Grade × Subject)

### 数学 / Mathematics

| 年级 | 核心主题 / Core Themes |
| --- | --- |
| G1 | 20 以内加减、120 以内数数与个位/十位、长度测量、时间（整点/半点）、平面图形与二分之一 |
| G2 | 1000 以内数与加减、长度单位与金钱、5 分钟读时、条形/象形图、图形等分与阵列（乘法萌芽） |
| G3 | 乘除法（100 以内）、分数作为数、多位数加减、面积与周长、时间/质量/容积、四边形 |
| G4 | 多位数乘法、带余除法、等值分数与分数加减、小数（到百分位）、因数/倍数、角度、对称 |
| G5 | 多位数与小数四则、异分母分数加减、分数乘除、体积、坐标平面、数值表达式、单位换算 |

### 英语语言艺术 / English Language Arts

| 年级 | 核心主题 / Core Themes |
| --- | --- |
| G1 | 拼读（双字母/含 e 长元音/元音组合）、看图认字、复述故事、三类写作启蒙、句子与标点 |
| G2 | 进阶拼读与前后缀、流利朗读、找主旨、比较文本版本、成段写作、不规则词 |
| G3 | 多音节词、中心思想、文本特征、观点立场、多段落写作、词性与主谓一致 |
| G4 | 主题归纳、概括、整合信息、修辞语言、结构化议论/说明文、关系代词与介词短语 |
| G5 | 引证文本、主题与概括、比较文本结构、跨文本研究、完成时态、连词运用 |

### 科学 / Science (NGSS)

| 年级 | 核心主题 / Core Themes |
| --- | --- |
| G1 | 波（光与声）、生物的结构与功能（动植物生存、亲代与子代）、太空系统（日月星辰的规律） |
| G2 | 物质的结构与性质、生态系统（植物需求、传粉与种子传播）、地球系统（地形、水、地图） |
| G3 | 力与相互作用（运动、磁）、生命周期与遗传/变异、适应与环境、天气与气候 |
| G4 | 能量（转移、碰撞、电）、波（信息传递）、结构功能与感官信息处理、地球特征（岩石、侵蚀、资源、灾害） |
| G5 | 物质（结构性质、守恒、混合物）、生态系统（物质与能量流、食物网）、地球系统（水分布、圈层相互作用）、太空（重力、恒星、天空规律） |

### 社会研究 / Social Studies

| 年级 | 核心主题 / Core Themes |
| --- | --- |
| G1 | 家庭与学校、过去与现在的家庭、规则与责任、地图与地球仪入门、需要与想要 |
| G2 | 社区与邻里、社区服务者、地方政府、商品与服务、基础经济、公民责任 |
| G3 | 远近社区与世界社区、地理区域、地方历史、政府结构、文化多样性 |
| G4 | 美国地理与区域、本州历史与地理、原住民、探险家、州政府、经济 |
| G5 | 美国早期历史（殖民地→独立→宪法）、美国地理、联邦政府三权、公民权、经济 |

## 5. 给产品的使用建议 / Notes for Product Use

- **关卡映射**：每个学科文件里「逐条知识点」的每一条，基本可以对应一个或一组游戏关卡 / mini-game。
- **难度梯度**：同一主题（如「分数」）跨年级反复出现且加深，适合做成贯穿多年的「成长线 / skill tree」。
- **跨学科**：测量（数学）+ 天气（科学）、地图（数学坐标 + 社会研究地理）等天然适合做综合关卡。
- **AI 出题**：知识点已拆到足够细的颗粒度，可直接作为 AI 自动生成题目 / 对话辅导的「知识点标签」。
